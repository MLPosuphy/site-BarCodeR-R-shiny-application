2. Arquitectura y flujos principales#

project history folders
  → recursive PNG scan (100 newest per folder)
  → optional matching RDS metadata
  → filters / favorites / tags
  → selection
  → GridStack composition
  → browser PNG export or RDS composition recipe

2.1. Estado reactivo y memoria#

Identificador Función
library() Inventario de PNG y metadatos RDS del proyecto actual.
selection() Claves seleccionadas en la galería.
open_tabs() Figuras abiertas en la cuadrícula.
grid_layout() Posiciones y dimensiones GridStack.
pinned() Figuras protegidas frente al reemplazo y cierre global.
tags_store() Favoritos y etiquetas persistidos en el proyecto.
Composiciones Recetas RDS que referencian figuras, disposición y fijaciones.

2.2. Main flows#

Flow Pipeline
Library scan project folders → latest 100 PNG per folder → matching RDS → searchable cards
Grid selection / drag-and-drop → open_tabs → GridStack layout → optional pinning
Composite export browser DOM grid → html-to-image → raster PNG download
Composition figure keys + layout + pins → project RDS → later partial restoration
Metadata tags.rds → favorites and tags shared within the project
