2. Arquitectura y flujos principales#

datasets() + active_ds()
  → selected_dataset_single
  → phyloseq extraction and temporary OTU orientation
  → sample / ASV / sequence / completeness metrics
  → Plotly and DT outputs
  → optional vegan::rarefy() computation

all in-memory datasets
  → compute_dataset_stats()
  → selected comparison subset
  → normalized heatmap / dotplot / baseline delta
  → filtration-log comparison

2.2. Cadenas de trazabilidad#

selected dataset
  → active_ds() synchronization
  → compute_dataset_stats() + sample/asv metrics
  → diagnostic cards and interactive plots
  → tables / CSV exports

Calculate curves
  → positive-count and ≥50-read checks
  → vegan::rarefy() on up to ~80 depths
  → cached rarefaction_result
  → individual or pooled-group rendering

5. Validación y control de integridad#

Control Función Efecto
Orientación OTU get_otu_taxa_rows() Solo transpone la matriz de cálculo; el phyloseq no cambia.
Agrupación get_group_var_choices() Conserva variables no temporales con 2 a 15 modalidades no ausentes.
Outliers iqr_outlier_flag() / iqr_distance_score() Detección global 1,5 IQR sobre reads, riqueza y dominancia.
Rarefacción vegan::rarefy() Requiere cuentas compatibles y excluye muestras con menos de 50 reads.
Tablas get_table_*_df() Añade ASV/SampleID y asegura nombres solo para visualización/exportación.
Vista Proyecto compute_dataset_stats() Suma dimensiones entre datasets sin deduplicación.
