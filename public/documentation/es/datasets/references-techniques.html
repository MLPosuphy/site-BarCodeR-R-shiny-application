2. Arquitectura y flujos principales#

datasets() + active_ds()
  → registry rendering
  → activate / rename / duplicate / reorder / delete
  → unsaved-state marker
  → bcr_save_registry()
  → save/projects/<slug>/registry.rds

project manager
  → manifest + .current pointer
  → save / restore / create / open / rename
  → duplicate / delete
  → ZIP export / import
  → full-session reload on project switch

2.1. Estado reactivo y memoria#

Identificador Función
datasets() Lista reactiva con nombre que contiene los objetos phyloseq presentes en memoria.
active_ds() Nombre del dataset utilizado como referencia global de la aplicación.
vals$persist_project() Callback global que guarda el registro actual.
vals$switch_project() Callback global que cambia de proyecto y recarga la sesión.
proj_tick() Contador reactivo que actualiza la lista y el tamaño de los proyectos.
rv$export_name Dataset seleccionado para la exportación individual.
rv$del_project_slug Slug del proyecto pendiente de confirmación de eliminación.

2.2. Cadenas de trazabilidad#

row action
  → Shiny input (activate/edit/duplicate/export/reorder/delete)
  → datasets() and/or active_ds() mutation
  → project marked unsaved
  → explicit Save project
  → registry.rds + manifest.rds

Open project
  → attempt to persist current project
  → bcr_write_current_slug()
  → session reload
  → bcr_load_registry() + UI-state restoration

5. Validación y control de integridad#

Capa Función Efecto
Nombre del dataset bcr_clean_label() / bcr_make_unique_label() Genera una clave segura y evita sobrescrituras silenciosas.
Linaje filtrado relabel_dataset_parents() Actualiza o borra parent_dataset en los descendientes reconocidos.
Persistencia bcr_save_registry() Escribe el registro de forma atómica y protege una copia no vacía frente a memoria vacía.
Proyecto actual .current + bcr_write_current_slug() Guarda el slug que se reabrirá al iniciar.
Archivo ZIP bcr_find_project_root() Busca registry.rds, manifest.rds o carpetas de historial conocidas.
Eliminación de proyecto bcr_delete_project() Rechaza el proyecto actual y comprueba que la carpeta desapareció.
