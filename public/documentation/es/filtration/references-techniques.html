2. Arquitectura y flujos principales#

datasets() + active_ds()
  → selected_ds_filtration
  → reactive block parameters
  → ps_filtered()
      taxonomy
      → abundance
      → samples
      → sequences
  → filtration_log
  → temporary result

temporary filtered phyloseq
  → save name normalization
  → optional overwrite confirmation
  → bcr_guard_ps()
  → add_dataset() / datasets()
  → active_ds()
  → explicit project save in Datasets

2.1. Estado reactivo y memoria#

Identificador Función
selected_ds_filtration Dataset padre sincronizado con active_ds().
ps_filtered() Phyloseq temporal recalculado automáticamente con cada parámetro activo.
advanced_conditions Lista reactiva de condiciones metadata combinadas por Y.
filtration_log Atributo que guarda dimensiones, textos, parámetros y elementos eliminados.
pending_overwrite_name Nombre limpiado pendiente de confirmación de sobrescritura.
datasets() / active_ds() Registro global actualizado solo al guardar el resultado.

2.2. Validación y control de integridad#

Capa Función Efecto
Orden fijo ps_filtered() Aplica taxonomía → abundancia → muestras → secuencias en una pasada.
Protección de taxones safe_prune_taxa() Rechaza una etapa que eliminaría todos los taxones.
Protección de muestras safe_prune_samples() Rechaza una etapa que eliminaría todas las muestras.
Secuencias get_refseq_aligned() Alinea RefSeq y conserva sin prueba las ASV no cubiertas si la cobertura es parcial.
Trazabilidad filtration_log$params Guarda parámetros estructurados independientemente del texto localizado.
Guardado submódulo io Añade o sobrescribe datasets(); un nombre vacío sustituye al padre.
Integridad bcr_guard_ps() Comprueba OTU, muestras y taxonomía antes de insertar.
