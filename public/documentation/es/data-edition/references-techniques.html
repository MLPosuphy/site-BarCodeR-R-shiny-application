2. Arquitectura y flujos principales#

datasets() + active_ds()
  → selected_dataset
  → metadata / OTU / taxonomy local editor state
  → immediate apply to the phyloseq object
  → datasets() replacement
  → edit_log append
  → explicit project save in Datasets

full component import
  → fileInput selection
  → identifier and coverage checks
  → slot replacement
  → local editors must be refreshed

2.1. Estado reactivo y memoria#

Identificador Función
selected_dataset Dataset editado y sincronizado con active_ds().
edit_log Atributo phyloseq que almacena el historial descriptivo de operaciones.
initial_data / previous_data Estados locales usados por Restablecer y Deshacer.
tax_edit_info_seen Indica si se mostró la advertencia previa a la edición taxonómica.
replacement_preview Inventario de celdas taxonómicas que coinciden con los patrones.
pending_save_label Nombre limpiado pendiente de confirmación de sobrescritura.

2.2. Cadenas de trazabilidad#

cell / structure action
  → capture previous local state
  → rebuild sample_data / otu_table / tax_table
  → update datasets()[selected_dataset]
  → append edit_log
  → mark project unsaved

Save under another name
  → edited source already changed
  → copy current edited state to a new registry key
  → new key becomes active
  → project still requires explicit disk save

5. Validación y control de integridad#

Control Función Efecto
Sincronización activa bcr_bind_active_picker() Vincula el selector con el dataset activo global.
Aplicación inmediata funciones apply_*() Reescribe el componente phyloseq y datasets() en cada acción.
Historial add_edit_log() Añade una entrada descriptiva sin snapshot completo del objeto anterior.
OTU numérica conversión matrix/numeric Los valores no convertibles pasan a NA con advertencia.
RefSeq / árbol realineación tras OTU Reordena o elimina el componente si deja de cubrir todos los taxones.
Importación completa handlers fileInput Reemplaza el slot al elegir el archivo, sin previsualización general.
Guardado en registro save_to_registry Copia o sobrescribe una entrada; no guarda el proyecto en disco.
