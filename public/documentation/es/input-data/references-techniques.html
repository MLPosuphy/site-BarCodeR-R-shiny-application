  → mt_prepare_loaded_phyloseq()
  → bcr_guard_ps() for a single dataset
  → datasets() registry
  → active_ds()
  → unsaved project state

2.1. Estado reactivo y memoria#

Identificador Función
pending_obj() Objeto cargado a la espera de confirmación.
pending_type() Tipo detectado: dataset o proyecto.
pending_file_name() Nombre original del archivo cargado.
pending_object_name() Nombre del objeto elegido dentro de un RData.
pending_candidates() Candidatos compatibles encontrados en un RData con varios objetos.
datasets() Registro reactivo de todos los datasets del proyecto BarCodeR actual.
active_ds() Nombre del dataset utilizado por defecto por los módulos posteriores.

5. Validación y control de integridad#

Capa Función Efecto
Archivo serializado readRDS() / load() Lee el objeto; RData se carga en un entorno aislado.
Detección detect_supported_object_type() Reconoce un phyloseq, un proyecto datasets/ps_registry o una lista de phyloseq.
Identificadores de muestras sanitize_sample_names() Translitera, sustituye caracteres inseguros y resuelve duplicados.
Celdas metadata vacías replace_empty_metadata_with_na() Convierte columnas a texto y sustituye celdas vacías por NA.
Estructura phyloseq bcr_guard_ps() Exige un phyloseq con OTU table y verifica identificadores de muestras/taxones.
Nombre del dataset bcr_clean_label() / bcr_make_unique_label() Crea una clave segura y única para el registro.
