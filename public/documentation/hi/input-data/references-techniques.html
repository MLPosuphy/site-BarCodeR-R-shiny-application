इनपुट डेटा — तकनीकी संदर्भ

इस BarCodeR संस्करण में मौजूद वास्तविक कोड से बनाया गया तकनीकी इन्वेंटरी।

यह पृष्ठ documentation-src/build_docs.py द्वारा दोबारा बनाया जाता है। Function names, identifiers और line numbers वर्तमान source code से आते हैं।

1. स्रोत फ़ाइलें#

भूमिका Path

2. आर्किटेक्चर और मुख्य डेटा प्रवाह#

fileInput rds_input
  → read_serialized_input()
  → detect_supported_object_type()
  → pending_obj / pending_type / pending_candidates
  → selection or confirmation modal
  → mt_prepare_loaded_phyloseq()
  → bcr_guard_ps() for a single dataset
  → datasets() registry
  → active_ds()
  → unsaved project state

2.1. Reactive state और memory#

Identifier भूमिका
pending_obj() User confirmation की प्रतीक्षा में loaded object।
pending_type() Detected type: dataset या project।
pending_file_name() Uploaded file का original name।
pending_object_name() RData के भीतर चुने गए object का name।
pending_candidates() Multi-object RData में मिले compatible candidates।
datasets() Current BarCodeR project के सभी datasets की reactive registry।
active_ds() Downstream modules द्वारा default रूप से उपयोग होने वाला dataset name।

2.2. Traceability chains#

single phyloseq
  → proposed label
  → add or replace modal
  → mt_prepare_loaded_phyloseq()
  → bcr_guard_ps()
  → datasets(new_registry)
  → active_ds(final_label)
  → detailed cleaning report

project object
  → datasets / ps_registry / list-of-phyloseq extraction
  → clean_project_phyloseq_list()
  → name collision resolution
  → merge or replace datasets()
  → active dataset restoration
  → aggregate restoration report

5. Validation और integrity guard#

Layer Function Effect
Serialized file readRDS() / load() Object पढ़ता है; RData isolated environment में load होता है।
Object detection detect_supported_object_type() Phyloseq, datasets/ps_registry project या phyloseq list पहचानता है।
Sample identifiers sanitize_sample_names() Transliteration, unsafe-character replacement और duplicate resolution करता है।
Metadata blanks replace_empty_metadata_with_na() Columns को character बनाकर empty cells को NA से बदलता है।
Phyloseq structure bcr_guard_ps() OTU table वाला phyloseq आवश्यक करता है और sample/taxon identifiers जाँचता है।
Dataset label bcr_clean_label() / bcr_make_unique_label() Registry के लिए safe और unique key बनाता है।
