2. आर्किटेक्चर और मुख्य डेटा प्रवाह#

datasets() + active_ds()
  → selected_dataset
  → metadata / OTU / taxonomy local editor state
  → immediate apply to the phyloseq object
  → datasets() replacement
  → edit_log append
  → explicit project save in Datasets

full component import
  → fileInput selection
  → identifier and coverage checks
  → slot replacement
  → local editors must be refreshed

2.1. Reactive state और memory#

Identifier भूमिका
selected_dataset active_ds() के साथ synchronized संपादित dataset।
edit_log Operations की descriptive audit entries रखने वाला phyloseq attribute।
initial_data / previous_data हर submodule में Reset और Undo के local states।
tax_edit_info_seen Taxonomy-edit warning दिखाया गया या नहीं।
replacement_preview Replacement patterns से मेल खाने वाली taxonomy cells की सूची।
pending_save_label Overwrite confirmation की प्रतीक्षा कर रहा cleaned name।

2.2. Traceability chains#

cell / structure action
  → capture previous local state
  → rebuild sample_data / otu_table / tax_table
  → update datasets()[selected_dataset]
  → append edit_log
  → mark project unsaved

Save under another name
  → edited source already changed
  → copy current edited state to a new registry key
  → new key becomes active
  → project still requires explicit disk save

5. Validation और integrity guard#

Control Function Effect
Active synchronization bcr_bind_active_picker() Data Edition picker को global active dataset से जोड़ता है।
Immediate application apply_*() functions हर action पर phyloseq component और datasets() पुनर्लिखे जाते हैं।
Audit trail add_edit_log() Previous object का full snapshot रखे बिना descriptive entry जोड़ता है।
Numeric OTU matrix/numeric conversion Non-convertible values NA बनते हैं और warning आती है।
RefSeq / tree post-OTU realignment सभी taxa cover न होने पर component reorder या remove होता है।
Full import fileInput handlers File चुनते ही selected slot replace होता है, general preview नहीं है।
Registry save save_to_registry Registry entry copy/overwrite करता है; project disk पर persist नहीं करता।
