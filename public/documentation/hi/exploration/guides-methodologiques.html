एक्सप्लोरेशन — पद्धति मार्गदर्शिका

1. उद्देश्य और संरचना#

Exploration project के phyloseq objects को visualize, summarize और compare करता है। इसमें Barplot, Alpha diversity, Venn/UpSet, Heat Tree, Phylogenetic tree और Taxonomic assignment quality शामिल हैं। कुछ outputs descriptive हैं; targeted taxon tests, Alpha statistics, ANCOM-BC और Faith PD comparisons inferential हैं।

2. सामान्य workflow#

अधिकांश tools scientific calculation और visual rendering को अलग रखते हैं। Dataset, group, rank, index, local filter या statistical method बदलने पर recalculation चाहिए; colors, dimensions, labels और layout आमतौर पर पिछले calculation को reuse करते हैं।

Scientific setting बदलने के बाद पुरानी figure दिखाई दे सकती है। Recalculation, figure regeneration और save status अवश्य देखें। कई local selectors active dataset को follow करते हैं, लेकिन local choice हमेशा active_ds() नहीं बदलता।

3. Local filtering#

Barplot, Alpha, Venn, Heat Tree और Taxonomic Quality अपने temporary local filters रख सकते हैं:

registry dataset → local staged filter → exploration result

यह global registry को overwrite नहीं करता, दूसरे tools में स्वतः लागू नहीं होता और persistent phyloseq नहीं बनाता। Result बचाने के लिए वही criteria Filtration में लागू करें, नया dataset save करें और project save करें।

4. Barplot#

Barplot sample या metadata group के अनुसार taxonomic composition दिखाता है। OTU table आवश्यक है; ranks के लिए taxonomy और grouping के लिए metadata चाहिए। Aggregation tax_glom(..., NArm = FALSE) से होती है, इसलिए unassigned taxa रखे जाते हैं।

Group mode में पहले reads pool होते हैं, फिर proportions calculate होते हैं। यह individual proportions का mean नहीं, depth-weighted pool है। Top N displayed data से बनता है और बाकी Other में जाते हैं। Threshold Top N के बाद लागू होता है; removed rows स्वतः Other में नहीं जातीं। 100%-stacked view remaining segments को visually renormalize करता है।

Selected taxon के लिए Student, Welch, Wilcoxon, ANOVA/Tukey, Welch ANOVA या Kruskal-Wallis data conditions के अनुसार चुना जा सकता है। Covariates भी जोड़ी जा सकती हैं। यह targeted test है, global compositional differential analysis नहीं।

5. Alpha diversity#

Indices में Observed, Shannon, Simpson, InvSimpson, Chao1, ACE, Fisher और Pielou शामिल हैं। Observed ≤ 1 पर Pielou missing होता है। Non-integer data को round नहीं किया जाता; Chao1, ACE और Fisher count-like data न होने पर missing रहते हैं।

Optional rarefaction rarefy_even_depth() और seed 2026 उपयोग करता है। Target zero होने पर हर dataset अपना positive minimum उपयोग करता है, common global depth नहीं। Rarefaction reads और samples हटा सकता है। Good coverage और rarefaction diagnostics integer counts मांगते हैं।

Statistics tab एक variable पर automatic parametric/non-parametric tests और कई variables पर Y ~ V1 + V2 या Y ~ V1 * V2 models चला सकता है। Residual diagnostics, R², Breusch-Pagan और emmeans उपलब्ध हो सकते हैं। Sparse interactions unstable हो सकती हैं।

6. Venn और UpSet#

यह presence/absence compare करता है। Element local filtering के बाद एक बार उपस्थित होने पर present माना जाता है। Inter-dataset mode में datasets sets हैं; intra-dataset mode में metadata levels sets हैं।

Elements taxonomic labels या exact RefSeq strings हो सकते हैं। Sequence mode alignment या similarity clustering नहीं करता। Regex ambiguous labels हटाती है; normalization prefixes, spaces, underscores और case harmonize करती है, पर distinct labels merge भी कर सकती है।

Venn अधिकतम सात sets तक है; उससे अधिक पर UpSet स्वतः उपयोग होता है। Intersection shared presence दिखाता है, समान abundance नहीं।

7. Heat Tree#

Modes: simple, descriptive differential और multiple-comparison matrix। Simple metrics sum, mean, occurrence, contributing ASVs, median, variance, relative abundance, log abundance, dominance और frequency हो सकते हैं।

Fast differential mode group medians का log2 ratio है और descriptive है—कोई p-value या multiple correction नहीं।

ANCOM-BC compositional inferential analysis देता है, जिसमें covariates, prevalence, library threshold, p-adjustment, alpha, structural zeros, convergence, pseudo-count और sensitivity settings हो सकती हैं। Test alpha बदलने पर recomputation चाहिए; q/logFC display thresholds केवल visual filters हैं।

हर rank और contrast पर ANCOM-BC अलग चलता है। k groups पर k(k-1)/2 contrasts होते हैं; ranks × contrasts बहुत महँगा हो सकता है, खासकर ASV level पर।

8. Phylogenetic tree#

पहले से phy_tree होना चाहिए; tool sequences से tree नहीं बनाता। यह rank aggregation, prevalence, total abundance, Top N और label cleaning उपयोग करता है। कम से कम तीन taxa रहने चाहिए।

Leaf metrics और tree diagnostics tips, nodes, branch lengths, rooting, ultrametricity, binary status, total length और height दिखाते हैं।

Faith PD picante उपलब्ध होने पर calculate होता है। यह display prevalence/abundance/Top-N filters से पहले calculate होता है, इसलिए वे Faith table नहीं बदलते। Partial tree कुछ taxa ignore कर सकता है; missing taxa और read coverage report होते हैं। Two groups के लिए Wilcoxon और तीन या अधिक के लिए Kruskal-Wallis उपयोग होता है।

Rendering engines ggtree, phyloseq और ape हैं; पूर्ण interactivity मुख्यतः ggtree में है।

9. Taxonomic assignment quality#

यह हर rank पर assigned taxa percentage, assigned reads percentage और strict continuous assignment depth calculate करता है। बहुत से unknown ASVs कुछ ही reads represent कर सकते हैं।

Unassigned patterns में NA, empty, unknown, unclassified, uncultured, environmental, metagenome, empty rank prefixes और sp. शामिल हैं। Strict depth पहली missing rank पर रुकता है; नीचे की rank उसे repair नहीं करती।

Contaminant patterns केवल calculation से taxa exclude करते हैं, dataset नहीं बदलते, लेकिन denominator बदलता है। Defaults marker के अनुसार बदलने चाहिए। Results rank, cumulative depth या दोनों में, percentages या counts के रूप में दिखते हैं।

10. Descriptive और inferential outputs#

Main Barplot, Venn, simple Heat Tree, phylogenetic display और assignment quality मुख्यतः descriptive हैं। Targeted Barplot tests, Alpha statistics, ANCOM-BC और Faith comparisons inferential हैं। Visual difference significance नहीं; significance causality नहीं।

11. Histories और reproducibility#

हर tool का project history folder अलग है: barplot/, alpha_div/, venn_diag/, heat_tree/, phylo_tree/figures/, tax_quality/। Visible result स्वतः save नहीं होता। Snapshot में PNG, RDS, metadata, parameters, calculated data, logs और XLSX हो सकते हैं।

Recent snapshots reproducible R code दे सकते हैं, जो snapshot RDS, package versions और dependencies पर निर्भर हो सकता है। Publication से पहले code review करें। History current project से जुड़ी है और internal trash नहीं है।

12. Scientific comparability#

Marker, region, technology, denoising/clustering, ASV/OTU definition, taxonomy database, ranks, samples, abundance type, filtering, normalization और depth compare करने से पहले match करें।

Rarefaction, Chao1, ACE, Fisher, Good coverage, ANCOM-BC और read/prevalence summaries count-like data मानते हैं। CLR/log data में presence और totals का अर्थ बदलता है। Taxonomic aggregation analysis unit बदलता है; group size pooled results और rare taxa detection को प्रभावित करता है।

13. Performance और dependencies#

Cost samples, taxa, datasets, indices, sets, ranks, contrasts और tree tips के साथ बढ़ता है। Multi-rank ANCOM-BC और large interactive trees विशेष रूप से महँगे हैं।

Packages में phyloseq, vegan, metacoder, ANCOMBC, ComplexUpset, ape, ggtree, picante, plotly, emmeans, lmtest और openxlsx हो सकते हैं। Missing package output disable या fallback कर सकता है; logs देखें।

Filtering, rank aggregation, groups/ranks/contrasts सीमित करना और heavy interactivity कम करना performance सुधारता है।

15. Checklists#

Exploration से पहले project, datasets, count/transformation status, tables, ranks, metadata types, groups और local filters जाँचें।

Statistics से पहले replicates, missing values, depth, assumptions, covariates, interactions, multiple correction और effect size जाँचें।

ANCOM-BC से पहले suitable counts, group/reference, higher ranks, limited contrasts और test alpha बनाम display q स्पष्ट करें।

Save से पहले calculation और rendering current हों, title/colors/dimensions/logs जाँचें, history save करें और tables export करें।

16. मुख्य सीमाएँ#

Independent local states, stale plots, pooled grouped compositions, non-integer richness limitations, per-dataset zero-depth rarefaction, first-occurrence Venn logic, label merging, descriptive median Heat Tree, costly ANCOM-BC, Faith on partial trees, regex-dependent quality और project-dependent snapshots।

17. Recommended workflow#

  1. Description में datasets inspect करें।
  2. Raw counts या transformed values तय करें।
  3. Groups और replicates जाँचें।
  4. Local filters केवल exploratory trials के लिए उपयोग करें।
  5. Simple descriptive plot से शुरू करें।
  6. Appropriate rank चुनें और displayed elements सीमित रखें।
  7. Scientific changes के बाद recompute करें।
  8. Valid design के बाद statistics चलाएँ।
  9. Logs और diagnostics पढ़ें।
  10. Figures, parameters और tables save करें।
  11. Reproducible R code review करें।
  12. Persistent filters Filtration में लागू कर project save करें।

18. सत्यापित आंतरिक स्रोत#

यह guide modules/exploration/ के main modules, _dirty_tracking.R, _active_dataset_sync.R तथा barplot, alpha, venn, heattree, phylotree और tax_quality code पर आधारित है, और architecture notes 30–35 से cross-check किया गया है।
