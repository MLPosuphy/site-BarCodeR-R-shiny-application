विवरण — कार्यपद्धति मार्गदर्शिका

1. सामान्य परिचय#

Description टैब BarCodeR में मौजूद phyloseq objects की संरचना और सामग्री को Data Edition, Filtration या statistical analysis से पहले जाँचने के लिए है।

यह दो complementary views में बाँटा गया है।

Dataset view#

एक समय में एक phyloseq object की जाँच करता है और आपको:

  • dimensions और उपलब्ध components देखने;
  • descriptive metrics पढ़ने;
  • abundance और observed richness visualize करने;
  • reference sequences जाँचने;
  • rarefaction curves calculate करने;
  • atypical samples पहचानने;
  • tables और logs देखने/निर्यात करने;
  • OpenMetaBar provenance पढ़ने देता है।

Project view#

Memory में मौजूद कई datasets की summary और comparison करता है: dimensions, depth, richness, sparsity, reference dataset से differences और filtration logs में recorded removals।

2. टैब का उद्देश्य#

Description का मुख्य उद्देश्य data समझना, import verify करना, स्पष्ट anomalies पहचानना, आगे के methodological choices तैयार करना और datasets की सामान्य संरचना compare करना है।

आवश्यकता उचित टैब
Tables बदलना Data Edition
Samples या taxa हटाना Filtration
Dataset rename/delete करना Datasets
Statistical analysis करना Analysis
FASTQ से pipeline चलाना OpenMetaBar

3. Data पर प्रभाव#

Description OTU table, taxonomy, metadata, sequences, tree, abundance, identifiers या logs को नहीं बदलता। Plots और tables memory में मौजूद object से बनते हैं।

3.1. अपवाद: active dataset#

Dataset-view selector global active dataset से synchronized है। यहाँ dataset बदलने पर:

  • active_ds() बदलता है;
  • BarCodeR के दूसरे tabs का default dataset बदलता है;
  • project unsaved mark हो सकता है।

Phyloseq content नहीं बदलता, लेकिन global working context बदलता है।

4. आवश्यक components#

अधिकांश functions के लिए कम से कम otu_table आवश्यक है।

Optional components:

  • sample_data;
  • tax_table;
  • refseq;
  • phylogenetic tree;
  • provenance attributes;
  • filtration logs।

किसी component की अनुपस्थिति उपलब्ध information घटाती है, पर टैब खुलना आवश्यक रूप से नहीं रोकती।

5. Abundance values के बारे में महत्वपूर्ण धारणा#

Module OTU-table values को reads कहता है, लेकिन यह verify नहीं करता कि वे raw, integer, untransformed और non-negative counts हैं।

Relative abundance, CLR/log transformation, normalization, decimal या negative values होने पर “reads” raw sequencing depth नहीं दर्शाते।

यह totals, richness, dominance, rarefaction और dataset comparisons की interpretation के लिए महत्वपूर्ण है।

7. Dataset चुनना#

Select a dataset field session में मौजूद सभी datasets दिखाता है।

7.1. Global synchronization#

यह global active dataset को follow करता है। Datasets, sidebar या किसी global selector में बदलाव Description में आता है; Description में बदलाव application के active dataset को बदलता है।

7.2. Fallback value#

Valid active dataset न होने पर पहले पिछला selected dataset, अन्यथा list का पहला dataset उपयोग होता है।

7.3. Dataset बदलना#

Metrics, plots, tables, grouping choices, provenance और outliers फिर से calculate होते हैं।

Rarefaction warning: dataset बदलने पर rarefaction automatically recalculate नहीं होता। Calculate curves फिर क्लिक करें।

8. Grouping variable#

Grouping variable — samples sample_data की किसी column से samples को रंग या समूह देता है।

8.1. उपलब्ध variables#

2 से 15 distinct non-missing values वाली columns प्रस्तावित होती हैं। Date, POSIXct, POSIXt excluded हैं।

8.2. Numeric columns#

2–15 distinct values वाली numeric column categorical group की तरह प्रस्तावित हो सकती है।

Temperature = 10, 15, 20

तीन groups माना जाएगा, continuous variable नहीं।

8.3. Missing values#

Missing values NA label में रखे जाते हैं। Literal "NA" और true missing visually समान लग सकते हैं।

8.4. No grouping#

No grouping पर सभी samples एक All group में जाते हैं।

8.5. Grouping के प्रभाव#

Grouping colors, violin plots, cumulative curves, rarefaction, outlier context और group concentration बदलता है; data नहीं बदलता।

9. Grouping outlier detection नहीं बदलता#

Outlier thresholds पूरे dataset पर calculate होते हैं, हर group के भीतर नहीं। Grouping केवल context और color देता है।

एक sample अपने group में normal होकर भी पूरे dataset के विरुद्ध outlier हो सकता है।

10. “View logs” button#

यह Tables and logs में Filtration logs sub-tab select करता है।

Current implementation automatic scroll या collapsed box खोलना सुनिश्चित नहीं करता। नीचे जाकर box manually खोलना पड़ सकता है।

11. Dataset header#

नाम, samples, taxa, total abundance और available components दिखाता है।

130 samples • 2,450 ASVs/OTUs • 7,779,736 reads

12. Component badges#

OTU table, taxonomy, metadata, reference sequences और filtration logs की presence दिखाते हैं।

12.1. OTU#

otu_table detected है।

12.2. Taxonomy#

tax_table मौजूद है, पर सभी ASV annotated, ranks complete या taxonomy correct होने की गारंटी नहीं।

12.3. Metadata#

sample_data मौजूद है, पर variables usable, types सही या missing values absent होने की गारंटी नहीं।

12.4. RefSeq#

Sequences मौजूद और Biostrings readable हैं। Biostrings unavailable होने पर refseq होते हुए भी absent दिख सकता है।

12.5. Logs#

filtration_log attribute की presence दिखाता है, पर actual removed rows होना सुनिश्चित नहीं।

12.6. Phylogenetic tree#

Tree के लिए badge नहीं है; badge absence से phy_tree की absence सिद्ध नहीं होती।

13. OTU-table orientation#

Description calculations के लिए matrix को अस्थायी रूप से taxa in rows और samples in columns बनाता है। Original phyloseq transpose या modify नहीं होता।

14. Metric: taxa count#

phyloseq::ntaxa(ps) के बराबर। UI ASV कहती है, लेकिन units OTU, ZOTU या अन्य हो सकती हैं।

15. Metric: sample count#

phyloseq::nsamples(ps) के बराबर।

16. Metric: total reads#

OTU table की सभी cells का sum, missing values छोड़कर। Raw counts होने पर ही इसे total reads माना जा सकता है।

17. Metric: reads per sample#

Reads = sample के सभी taxa abundance का sum

Minimum, maximum, mean, median और standard deviation calculate होते हैं; main cards में median दिखता है।

18. Metric: observed richness#

Richness = abundance > 0 वाले taxa की संख्या

यह raw observed richness है, Chao1, ACE, Shannon, Simpson या depth-corrected richness नहीं।

19. Metric: dominant taxon percentage#

Dominance (%) =
maximum taxon abundance
÷ total sample abundance
× 100

High dominance वास्तविक biology, preferential amplification, contaminant, compositional imbalance या low depth से आ सकती है; अकेले poor quality साबित नहीं करती।

20. Metric: zero proportion per sample#

Zeros (%) =
zero abundance taxa
÷ total taxa
× 100

Current outlier detection में इसका उपयोग नहीं होता।

21. Metric: global sparsity#

zero cells
÷ total OTU-table cells
× 100

21.1. Interpretation#

Metabarcoding में diversity, specialization, spatial variation, detection limits, depth और processing के कारण high sparsity सामान्य है।

21.2. Display thresholds#

Sparsity Message
≥ 97% Very high
90–<97% High
<90% Controlled

ये internal display rules हैं, universal scientific standards नहीं।

21.3. NA का प्रभाव#

NA zero नहीं गिने जाते, पर denominator में रहते हैं; sparsity थोड़ा underestimate हो सकती है।

22. Depth variability#

CV (%) =
SD of reads per sample
÷ mean reads per sample
× 100

CV ≥ 100% पर बहुत heterogeneous depth message दिखता है। यह internal descriptive threshold है।

23. Taxonomic completeness#

Completeness (%) =
non-missing, non-empty values
÷ total ASVs
× 100

Displayed mean सभी ranks का unweighted average है।

23.1. Consequence#

Average कुछ complete और कुछ बहुत incomplete ranks के अंतर छिपा सकता है; detailed table देखें।

23.2. Space-only strings#

Cleaning न होने पर केवल spaces वाली string filled मानी जा सकती है।

24. Missing metadata values#

Missing (%) =
NA या empty strings
÷ samples
× 100

Displayed mean variables का unweighted average है।

24.1. "NA" value#

Literal "NA" true missing नहीं और level के रूप में count हो सकता है।

24.2. Spaces#

Space-only string non-missing मानी जा सकती है।

24.3. Displayed type#

Table column की first R class दिखाती है: character, numeric, factor, Date, आदि।

25. Sequence length#

refseq और Biostrings उपलब्ध होने पर minimum, maximum, mean, median और SD bp में calculate होते हैं।

25.1. Interpretation#

Multimodal या wide distribution multiple regions, markers, truncated sequences, indels, nonspecific products, insufficient filtering या real variation दिखा सकती है।

26. GC percentage#

GC (%) =
G + C
÷ A + C + G + T
× 100

Ambiguous bases denominator में नहीं आते; GC केवल unambiguous भाग पर आधारित हो सकता है।

27. Sequence names#

refseq names उपयोग होते हैं। Invalid/absent names पर:

ASV_1
ASV_2
ASV_3

बनते हैं। OTU taxa से correspondence exhaustive रूप से verify नहीं होती।

28. Automatic interpretation message#

Median reads, median richness, sparsity और components से summary text बनता है। यह descriptive help है, scientific validation या filtering recommendation नहीं।

29. Quick dataset reading#

29.1. Structure#

Median reads, median richness और sparsity।

29.2. Available content#

OTU, taxonomy, metadata और sequences की presence।

29.3. Sequences#

Available होने पर median length और GC।

29.4. Filtration#

filtration_log होने पर removed ASV और samples की संख्या।

30. Automatic diagnostics#

High sparsity, heterogeneous depth, missing metadata/taxonomy/sequences और filtration history संकेत कर सकता है। यह data modify नहीं करता और अकेले exclusion decision नहीं होना चाहिए।

31.1. Run summary#

ID, label, date, technology, marker, engine, database, design, samples और FASTQ count हो सकते हैं।

31.2. Demultiplexing#

MiniBar activation, method और tolerances हो सकते हैं।

31.3. Filters#

Orientation, quality, length, coding filter और genetic code।

31.4. LotuS3#

Platform, amplicon type, clustering और assignment।

31.5. LCA#

Coverage, identity thresholds, agreement और mode।

31.6. IDMABIO#

केवल संबंधित route पर।

31.7. NextITS#

केवल संबंधित route पर।

31.8. Cluster environment#

Partition, memory, CPUs, modules और paths।

31.9. FASTQ files#

Recorded provenance paths हैं; files अभी accessible हों यह आवश्यक नहीं।

31.10. Sample renaming#

Original/corrected name, date और reason हो सकते हैं।

31.11. Missing provenance#

यह सिद्ध नहीं करता कि dataset OpenMetaBar से नहीं आया; attribute conversion, old version या export में खो सकता है।

34.2. Displayed metadata#

35. Top 15 samples#

Total abundance के अनुसार अधिकतम 15 samples। Bar click sample card update करता है।

35.1. Limitation#

36. Top 15 taxa#

Total abundance के आधार पर rank और tooltip में prevalence।

36.1. Prevalence#

Prevalence = abundance > 0 वाले samples

37. Cumulative sample contribution#

Samples abundance से rank होकर cumulative proportion दिखाते हैं। शुरुआती तेज वृद्धि depth concentration दर्शाती है।

38. Cumulative taxon contribution#

Dominant taxa की cumulative abundance दिखती है; taxonomy, prevalence, group या rarity शामिल नहीं।

39. Abundance tab#

Reads histogram, reads by group violin और cumulative reads by group।

40. Reads histogram#

Per-sample total abundance distribution, skewness और depth populations दिखाता है। Plotly bins automatically चुनता है।

41. Reads by group#

Multiple groups होने पर violin plot distribution, boxplot, mean और individual points दिखाता है।

41.1. No grouping#

Qualitative grouping variable unavailable होने पर message दिखता है।

41.2. Interpretation#

यह descriptive है; statistical test, normalization, group-size adjustment या covariate correction नहीं करता।

42. Cumulative reads by group#

हर group के भीतर samples abundance से sort होते हैं और cumulative percentage group के अंदर calculate होती है। हर curve 100% तक पहुँचती है।

42.1. Consequence#

यह group के अंदर depth concentration दिखाता है, project reads में group का share नहीं। छोटे और बड़े group दोनों 100% पहुँचते हैं।

43. Richness tab#

Richness histogram, richness by group और richness versus dominance शामिल हैं।

44. Richness histogram#

Per-sample observed taxa distribution दिखाता है। Depth correction नहीं है, इसलिए deeper sample में अधिक taxa दिख सकते हैं।

45. Richness by group#

Violin plot groups के observed richness की descriptive comparison करता है; कोई statistical test नहीं।

46. Richness versus dominance#

X = observed richness
Y = dominant taxon percentage

Rich/even, rich/dominated, poor/dominated और atypical profiles पहचानने में मदद करता है।

46.1. यह evenness index नहीं है#

Maximum dominance Pielou, Shannon या Simpson के बराबर नहीं। समान maximum dominance वाली communities के बाकी taxa बहुत अलग हो सकते हैं।

47. Sequences tab#

Length histogram, GC histogram और length versus GC। refseq और Biostrings आवश्यक हैं।

48. Length versus GC#

हर point एक sequence है। अलग length/composition groups, extreme sequences या multiple markers दिख सकते हैं, लेकिन contamination अकेले सिद्ध नहीं होती।

49. Rarefaction curves#

Calculation अलग से चलती है और tab खुलने पर automatic नहीं। Calculate curves क्लिक करें।

50. Rarefaction method#

Module उपयोग करता है:

vegan::rarefy()

यह दिए गए depth पर expected observed taxa analytically calculate करता है। यह repeated random subsampling नहीं, नया phyloseq नहीं बनाता, rarefy_even_depth() नहीं चलाता और data normalize/save नहीं करता।

51. Calculation requirements#

vegan, OTU table, कम से कम दो positive samples और कम से कम दो samples with ≥50 reads आवश्यक हैं। 50 से कम reads वाले samples exclude होते हैं।

51.1. 50-read threshold#

Code में fixed है, UI से बदल नहीं सकता और universal standard नहीं।

52. Expected data type#

vegan::rarefy() counts के लिए है। Relative abundance, CLR, negative, continuous transformed या non-integer values उचित नहीं। Module सभी गलत cases block नहीं करता।

53. Calculated depths#

लगभग 80 depths, 1 से observed maximum तक। हर sample के लिए उसके total से अधिक depths हटते हैं; values round और deduplicate होती हैं।

54. Individual curves#

हर sample की एक line, group के अनुसार color। Tooltip में SampleID, group, total reads, rarefied depth, expected/observed richness और outlier status।

55. Individual-curve subset#

Options: All samples, Top reads, Bottom reads, Outliers।

55.1. All samples#

सभी eligible curves। Current implementation में maximum curve limit लागू नहीं, इसलिए plot भारी हो सकता है।

55.2. Top reads#

Selected limit तक deepest samples।

55.3. Bottom reads#

≥50 reads वाले samples में shallowest।

55.4. Outliers#

IQR outliers। कोई outlier न होने पर plot empty हो सकता है।

56. Maximum number of curves#

2 से 200। Top, Bottom और Outliers पर लागू; All पर नहीं।

57. Curves aggregated by group#

Group के सभी samples का abundance sum करके pooled community की curve बनती है।

57.1. Curve क्या दर्शाती है#

Group के pooled reads में expected richness। यह individual curves का mean, per-sample mean या confidence interval नहीं।

57.2. Group size effect#

More samples/reads वाला group larger pool और higher richness पा सकता है। Sample count और total reads साथ देखें।

57.3. Without grouping#

सभी samples एक All curve में pool होते हैं।

58. Legend दिखाना#

Default off। Many groups पर readability घट सकती है। Individual mode में हर group की एक legend entry होती है।

59. Recalculation आवश्यक#

Result उस dataset से जुड़ा है जो button click पर active था। Dataset बदलना automatic recalculate नहीं करता।

59.1. Grouping बदलना#

Existing result से colors या aggregation update हो सकते हैं।

59.2. Stale-result risk#

Dataset change के बाद हमेशा calculation दोहराएँ।

60. Rarefaction interpretation#

Flattening curve में नए reads से कम नए taxa जुड़ते हैं। Strongly increasing curve अधिक depth से और taxa मिलने की संभावना दिखाती है।

Plateau absence poor quality आवश्यक रूप से नहीं; high diversity, rare taxa, noise, errors या biological heterogeneity कारण हो सकते हैं।

61. Rarefaction limitations#

Confidence interval, repeated random mean, extrapolation, Good's coverage, Chao1, statistical comparison या automatic saturation threshold नहीं।

62. Outlier detection#

Depth, richness और dominance उपयोग होते हैं। Zero proportion उपयोग नहीं।

63. IQR rule#

Q1 = first quartile
Q3 = third quartile
IQR = Q3 - Q1
Lower = Q1 - 1.5 × IQR
Upper = Q3 + 1.5 × IQR

Limits के बाहर Tukey outlier mark होता है।

64. High और low outliers#

Depth, richness और dominance के दोनों extremes detect होते हैं, जिसमें unusually low dominance भी शामिल है।

65. Minimum conditions#

चार से कम values, all missing या IQR zero होने पर उस metric का outlier नहीं मिलता।

66. Sample status#

कम से कम एक atypical metric पर Outlier, अन्यथा Standard। Automatic deletion नहीं।

67. Signal count#

Depth, richness, dominance में atypical metrics की संख्या 0–3। More signals higher review priority।

68. Outlier score#

Limits से बाहर distance IQR units में और तीन metrics पर sum।

68.1. Interpretation#

Higher score farther exceedance दिखाता है; probability, p-value, universal quality या deletion threshold नहीं।

69. Priority order#

Signal count, global score और reads से sort। पहला spotlight sample।

70. Outlier summary#

Total, percentage, metric-specific counts, most frequent signal और most affected group।

71. Group concentration#

Outlier % = group outliers ÷ group samples × 100

Top four groups दिखते हैं।

71.1. Color thresholds#

Percentage Level
≥30% Danger
15–<30% Warning
<15% Low

Visual conventions हैं, statistical thresholds नहीं।

72. Global detection और group reading#

Thresholds पूरे dataset पर calculate होते हैं, फिर group percentages। Naturally different group technical problem के बिना many outliers दिखा सकता है।

73. Samples-to-watch table#

SampleID, group, signals, count, score, reads, richness और dominance। केवल outliers; search, filters और export उपलब्ध।

74. Complete sample table#

SampleID, group, signals, reads, richness, dominance, zeros और status। Outliers पहले।

75. Outlier का अर्थ क्या नहीं है#

यह automatic error, contaminant, remove करने योग्य sample, sequencing failure या bad control नहीं। Biology, group difference, low biomass या rare event हो सकता है। Metadata, protocol, controls, logs और plots के साथ interpret करें।

76. Tables and logs#

Initially collapsed। OTU table, Taxonomy, Metadata, Completeness और Filtration logs शामिल।

77. Table summary#

OTU, taxonomy, metadata dimensions और exportable log rows। Display identifier column dimensions में शामिल नहीं।

78. Displayed OTU table#

Taxa rows और samples columns; ASV column जोड़ता है, भले units OTU/ZOTU हों।

78.1. Original orientation#

Export standardized orientation उपयोग करता है, original आवश्यक नहीं।

78.2. Content#

Values unchanged; integer, decimal, negative, transformed या missing हो सकते हैं।

79. Displayed taxonomy#

ASV column और ranks।

79.1. Rank names#

Empty/duplicate names display/export के लिए unique होते हैं; original tax_table नहीं बदलता।

80. Displayed metadata#

sample_data rownames SampleID column बनते हैं। Existing SampleID column SampleID_meta आदि बनती है। Original object नहीं बदलता।

81. Interactive table functions#

Column filters, search, vertical/horizontal scroll, fixed first column, pagination, Copy और CSV उपलब्ध। Large matrix पूरी तरह R memory में तैयार होती है।

Dedicated button complete calculated table export करता है, केवल visible/filtered rows नहीं।

82.3. Missing component#

Component absent होने पर empty CSV बन सकता है।

83. Taxonomic completeness#

हर rank का filled और missing percentage दिखता है, जिससे complete या empty ranks पहचानते हैं।

84. Metadata completeness#

हर variable का R type, missing percentage और unique values दिखते हैं। Empty, constant, grouping candidates और text बनी numeric columns पहचानने में मदद।

85. Groupable variables#

2–15 levels वाली non-temporal columns। Biological relevance की गारंटी नहीं।

89. Project view#

Memory के datasets() objects पर काम करता है, disk पर saved सभी projects पर नहीं।

90. Global project summary#

Loaded datasets, selected datasets, summed samples, summed abundance और mean sparsity।

91. Cumulative samples#

हर dataset के sample count का sum, unique sample count नहीं। Same samples multiple datasets में repeated count होते हैं।

Datasets की simple mean sparsity। हर dataset बराबर weight रखता है, size की परवाह नहीं।

94. Project summary table#

Dataset, ASV, samples, total reads, mean/median, mean richness, sparsity, completeness, metadata missingness, components, logs और removals।

95. Datasets to compare#

True parentage, same samples, untransformed abundance, log presence और renamed/deleted parent verify करें।

107. Performance#

Large matrix sums, all-dataset metrics, full table conversion, sequence calculations, rarefaction, Plotly और many-dataset comparison memory-intensive हैं।

107.1. Lazy initialization#

Description tab खोलने पर module initialize होता है; first display धीमा हो सकता है।

107.2. Large tables#

107.3. Rarefaction#

Hundreds of curves browser धीमा कर सकती हैं; Top, Bottom या Outliers चुनें।

108. समस्या समाधान#

108.1. कोई dataset नहीं दिखता#

No dataset, wrong project, failed import या missing registry। Input data, OpenMetaBar या Datasets उपयोग करें।

108.2. Dataset अन्य tabs में भी बदलता है#

Selector global active dataset से synchronized है; यह expected है।

108.3. केवल देखने के बाद project unsaved#

Active dataset बदला होगा। Persist करना हो तो save करें।

108.4. Reads decimal हैं#

OTU table transformed/normalized हो सकती है। Depth और rarefaction को raw counts न मानें।

108.5. Richness inconsistent#

Transformation, negative values, unpruned taxa, depth, structural zeros या orientation कारण हो सकते हैं। केवल >0 values count होती हैं।

108.6. Sparsity बहुत कम#

NA denominator में हैं लेकिन zero नहीं गिने जाते।

108.7. Group variable नहीं#

Metadata absent, one/>15 levels, date variable या all missing।

108.8. Numeric variable group बनती है#

2–15 distinct values हैं। Categorical interpretation गलत हो तो select न करें।

108.9. Missing values NA group बनती हैं#

Description missing को label बनाता है; जरूरत हो तो metadata साफ़ करें।

108.10. View logs कुछ नहीं करता#

केवल sub-tab select करता है; box manually खोलें।

108.11. Sequences absent#

No refseq, Biostrings unavailable या invalid object।

108.12. GC unusual#

Ambiguous bases, short sequences, multiple markers या non-ACGT characters।

108.13. Rank names बदल गए#

Display/export के लिए unique किए गए; original unchanged।

108.14. SampleID_meta दिखता है#

Metadata में पहले SampleID था; rownames के लिए SampleID reserved है।

108.15. Rarefaction calculate नहीं#

Missing vegan, OTU, enough samples/reads या incompatible data।

108.16. Curves पुराने dataset की हैं#

Dataset change के बाद recalculate नहीं किया। फिर Calculate करें।

108.17. Maximum curves respected नहीं#

All mode limit ignore करता है।

108.18. Large group pooled curve बहुत ऊँची#

Group reads sum हुए हैं; per-sample mean नहीं।

108.19. कोई outlier नहीं#

True homogeneity, few samples, zero IQR या missing values।

108.20. Biologically normal sample flagged#

Rule global है, within-group नहीं। Context से interpret करें।

108.21. Very atypical sample flagged नहीं#

Metric unused, zero IQR, few samples, only zero-proportion issue या transformed data।

108.22. 30% outlier group red#

Internal visual threshold है, p-value नहीं।

108.23. OTU export orientation अलग#

Taxa हमेशा rows में export होते हैं।

108.24. CSV visual filter से अलग#

Dedicated button full table export करता है; current DataTables state के लिए built-in CSV उपयोग करें।

108.25. CSV empty#

Corresponding component absent हो सकता है।

108.26. Logs absent#

BarCodeR filtration नहीं, attribute lost, other tool या old version।

108.27. Project view samples double-count करता है#

Cross-dataset sums deduplicate नहीं करते।

108.28. Heatmap similar लगती है#

हर metric अलग 0–1 normalize होती है।

108.29. Column 0.5 है#

सभी datasets का value समान है।

108.30. Chosen reference उपयोग नहीं#

Selection में शामिल नहीं; जोड़ें।

108.31. Difference plot नहीं#

Zero/missing reference, one dataset या missing metric।

108.32. Filtration comparison unfair#

Absolute counts हैं; initial dimensions के अनुसार interpret करें।

108.33. Project view धीमी#

Datasets/selection घटाएँ और large tables न खोलें।

109. Dataset खोलने की checklist#

  • Dataset name, samples और taxa verify करें।
  • Total abundance और raw/transformed nature जाँचें।
  • Taxonomy, metadata, sequences और logs देखें।
  • Sparsity/depth alerts पढ़ें।

110. Group analysis से पहले checklist#

  • Biologically relevant variable चुनें।
  • Levels, missing values और group sizes जाँचें।
  • Numeric variable को गलती से category न मानें।
  • Depth, richness और outliers देखें।
  • Description को statistical test न समझें।

111. Rarefaction से पहले checklist#

  • Raw, integer, non-negative counts verify करें।
  • कम से कम दो samples with 50 reads।
  • सही dataset/group चुनें।
  • Calculate करें और dataset change के बाद फिर करें।
  • Individual curves और pooled groups अलग समझें।
  • Plateau को definitive validation न मानें।

112. Outlier हटाने से पहले checklist#

  • Metrics, metadata, group, controls और logs जाँचें।
  • Depth और dominance देखें।
  • Biological expectation तय करें।
  • Description से delete न करें।
  • Justification के साथ Filtration उपयोग करें।

113. Dataset comparison से पहले checklist#

  • Same abundance type और units।
  • Same marker या explicit objective।
  • Comparable technology, filters और samples।
  • Reference selection में।
  • Non-deduplicated sums और 0–1 normalization समझें।
  • “Higher” को “better” न मानें।
