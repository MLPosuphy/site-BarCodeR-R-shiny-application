MultiView — पद्धति संबंधी मार्गदर्शिका

1. सामान्य भूमिका#

MultiView BarCodeR के scientific modules में पहले से save की गई figures को खोजता, filter करता, favorite/tag करता और GridStack grid में move/resize करके composite PNG या layout composition बनाता है। यह कोई scientific recalculation नहीं करता, Plotly interactivity restore नहीं करता, axes synchronize नहीं करता और analysis parameters/colors नहीं बदलता। Analysis बदलने के लिए source module पर लौटें।

2. Figures का स्रोत#

Current project के save/projects/<project>/ folders recursively scan होते हैं; MultiView का अपना folder exclude होता है। Type path से derive होता है और manually placed PNG भी दिख सकता है। हर folder के केवल 100 सबसे हाल में modified PNG load होते हैं; pagination नहीं है और date filter cap से बाहर files वापस नहीं ला सकता।

3. PNG/RDS pairing#

PNG केवल उसी exact basename वाले RDS से pair होता है। दोनों होने पर dataset, description, parameters और badges मिलते हैं; केवल PNG limited metadata के साथ दिखता है; केवल RDS नहीं दिखता। Reader datasets, transformation, distance, taxonomic rank, group, permutations और seed खोजता है; non-standard snapshots incomplete हो सकते हैं।

4. Loading और refresh#

Scan MultiView खुलने पर ही शुरू होता है। Refresh manual rescan करता है; auto-refresh active tab में हर 10 seconds चलता है और network disk/large RDS पर महंगा हो सकता है। Displayed date PNG modification time है, analysis date नहीं।

5. Search, filters और sorting#

Type, exact dataset label, date, favorites और tags से filter करें; multiple tags OR logic उपयोग करते हैं। Literal case-insensitive search key, dataset, description और parameters पर चलता है। Multi-dataset run combined label हो सकता है। KPI orphan favorites को भी count कर सकता है।

6. Gallery और table#

Gallery preview, type, filename, date, dataset, badges, tags और favorite दिखाती है। “Comparable” केवल same type + same dataset label है; transformation, distance, filtering, rank, groups, axes या method validate नहीं होते। Table selection open/replace actions से linked नहीं है, इसलिए multi-selection Gallery में करें।

7. Figure selection#

Checkbox/Space select, click/Enter details, double-click या drag-drop grid में add, star favorite और Escape panel close करता है। Select All केवल visible cards चुनता है, पर filter बदलने के बाद hidden selection रह सकती है। नई comparison से पहले Clear selection करें। बहुत बड़ी selection browser को धीमा कर सकती है।

8. Details panel#

Large image, type, date, dataset, key, main/technical parameters, tags, favorite, PNG download और grid opening दिखाता है। Scientific RDS download, source module खोलना, R code generate करना, analysis rerun करना या parameter sets auto-compare करना उपलब्ध नहीं है।

9. Favorites और tags#

save/projects/<project>/multiview/tags.rds में तुरंत save होते हैं; पुराना save/multiview/tags.rds message obsolete है। Tags comma/semicolon accept करते हैं। Deleted PNG orphan references छोड़ते हैं। Same project की sessions state share करती हैं; user isolation और full concurrent locking नहीं है।

10. Open analyses grid#

Selection, double-click, drag-drop या details से figures add होती हैं; duplicate रोका जाता है। 12-column grid का default दो cards per row है (width 6, height 6)। object-fit: contain पूरा PNG रखता है पर whitespace हो सकता है; resize resolution नहीं बढ़ाता। Edit mode move/resize control करता है; card close करने से files delete नहीं होतीं।

11. Pin, replace और close#

Pinned cards Replace और Close all से बचते हैं, लेकिन move/resize/individual close हो सकते हैं। Replace pins रखता, बाकी हटाता और current selection जोड़ता है।

12. Layout presets#

1×2, 2×2, 1×3, 3×1 और Hero+2 उपलब्ध हैं। Slots से अधिक figures last position reuse करके overlap कर सकती हैं। Manually rearrange, दूसरा preset या कम figures चुनें। Reset default layout देता है, cards close नहीं करता।

13. Composite PNG export#

html-to-image white background और pixelRatio 2 के साथ पूरे grid DOM को capture करता है, इसलिए titles, metadata और buttons भी आ सकते हैं। यह scientific PNGs की clean merge नहीं है। Output browser-side raster PNG है, history में नहीं जुड़ता और structured data नहीं रखता। PDF/SVG/TIFF/PowerPoint/interactive HTML नहीं है। Large grid, huge PNG, missing CDN या empty grid समस्या दे सकते हैं।

14. Composition save करना#

multiview/compositions/ का RDS name, description, date, figure keys, layout, dimensions, pins और filter values रखता है। यह PNG, scientific RDS, phyloseq, tables, tags या favorites copy नहीं करता; केवल layout recipe है। Load केवल existing figures, layout और pins restore करता है; saved filters reapply नहीं होते। Missing/renamed files omit हो जाती हैं।

15. Composition import/export#

Export recipe RDS download करता है। Import मुख्यतः list में tabs verify करके current project में copy करता है, auto-load नहीं करता। Recipe अकेली portable नहीं है: target project में identical type+filename keys चाहिए। Sharing के लिए composite PNG या original PNG/RDS दें। External PNG direct import उपलब्ध नहीं है।

16. Figures सही तरह compare करना#

Dataset, samples, filtering, transformation, normalization, rank, method, distance, groups, axes, limits, units, colors, categories, thresholds और data version verify करें। Top N/Other barplots बदल सकते हैं; independent ordinations rotate/invert हो सकती हैं और quantitative comparison के लिए Procrustes चाहिए; volcano plots की references/effect units अलग हो सकती हैं। MultiView organization/presentation tool है, statistical comparison नहीं।

17. Projects, sessions और multi-user#

Library, tags, favorites और compositions current project के साथ बदलते हैं। Live grid session-only है जब तक composition save न हो। कुछ settings restore होती हैं, पर dataset/tag/date filters, selection और unsaved layout नहीं। Static Shiny resources process-wide हैं; concurrent projects wrong resource दिखा सकते हैं। State user-isolated नहीं है, इसलिए concurrent multi-user deployment पूरी तरह सुरक्षित नहीं।

18. External dependencies और offline use#

GridStack, SortableJS और html-to-image jsDelivr से load होते हैं। Offline browsing कुछ हद तक चलेगी, पर move, resize, drag-drop, presets या export fail हो सकते हैं। GridStack लगभग 6 seconds wait करके छोड़ देता है। Full offline के लिए libraries www/ में bundle करें।

19. Troubleshooting#

समस्या कारण समाधान
कोई figure नहीं Saved PNG नहीं Scientific module में save करें
नई figure missing Rescan नहीं हुआ Refresh
पुरानी figure missing 100-file cap Folder inspect/archive करें
Parameters missing RDS absent/mismatch Basename ठीक करें
Table selection काम नहीं State से link नहीं Gallery उपयोग करें
Cards overlap Preset slots कम Manually arrange करें
Composition incomplete Source files missing Histories restore करें
Filters restore नहीं Current loader behavior Manually set करें

20. Checklists#

Compose से पहले project, refresh, PNG/RDS pairs, parameters, old selection और card count जाँचें। Scientific comparison से पहले data, filters, methods, ranks, axes, units, colors और thresholds harmonize करें। Export से पहले overlap/resolution जाँचें और downloaded file खोलें। Save से पहले layout/pins, name/description, non-copied images और reload test समझें; portable PNG भी export करें।

21. मुख्य सीमाएँ#

PNG-only library, lost interactivity, no recomputation/axis harmonization, 100-file cap, mtime dates, RDS-dependent metadata, Table-selection bug, weak comparable badge, orphan/shared tags, overlapping presets, controls सहित raster export, non-self-contained recipes, filters not restored, CDN dependence, multi-user fragility और unsaved grid loss।

22. Recommended workflow#

Source figures save करें; MultiView खोलकर refresh करें; filter और parameters inspect करें; tags/favorites जोड़ें; Gallery में select करें; grid खोलें; scientific comparability verify करें; preset और manual adjustment करें; key cards pin करें; PNG export/check करें; composition save/reload test करें; original histories रखें और conclusions के लिए statistical tables उपयोग करें।
