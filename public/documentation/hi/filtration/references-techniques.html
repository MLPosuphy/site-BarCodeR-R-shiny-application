फ़िल्ट्रेशन — तकनीकी संदर्भ

इस BarCodeR संस्करण में मौजूद वास्तविक कोड से बनाया गया तकनीकी इन्वेंटरी।

यह पृष्ठ documentation-src/build_docs.py द्वारा दोबारा बनाया जाता है। Function names, identifiers और line numbers वर्तमान source code से आते हैं।

2. आर्किटेक्चर और मुख्य डेटा प्रवाह#

datasets() + active_ds()
  → selected_ds_filtration
  → reactive block parameters
  → ps_filtered()
      taxonomy
      → abundance
      → samples
      → sequences
  → filtration_log
  → temporary result

temporary filtered phyloseq
  → save name normalization
  → optional overwrite confirmation
  → bcr_guard_ps()
  → add_dataset() / datasets()
  → active_ds()
  → explicit project save in Datasets

2.1. Reactive state और memory#

Identifier भूमिका
selected_ds_filtration active_ds() से synchronized parent dataset।
ps_filtered() हर active parameter पर automatically recalculated temporary phyloseq।
advanced_conditions AND से जुड़ी metadata conditions की reactive list।
filtration_log Dimensions, text, parameters और removed items रखने वाला result attribute।
pending_overwrite_name Overwrite confirmation की प्रतीक्षा कर रहा cleaned name।
datasets() / active_ds() Result save होने पर ही update होने वाला global registry।

2.2. Validation और integrity guard#

Layer Function Effect
Fixed order ps_filtered() Taxonomy → abundance → samples → sequences एक pass में लागू करता है।
Taxon safeguard safe_prune_taxa() सभी taxa हटाने वाली step को रोकता है।
Sample safeguard safe_prune_samples() सभी samples हटाने वाली step को रोकता है।
Sequences get_refseq_aligned() RefSeq align करता है और partial coverage में uncovered ASV बिना test रखता है।
Traceability filtration_log$params Localized text से अलग structured parameters रखता है।
Saving io submodule datasets() add/overwrite करता है; empty name parent replace करता है।
Integrity bcr_guard_ps() Registry insertion से पहले OTU, samples और taxonomy consistency जाँचता है।
