विश्लेषण — पद्धति मार्गदर्शिका

1. उद्देश्य और संरचना#

विश्लेषण tab में छह families हैं: differential abundance, ordination, matrix comparison, association networks, PERMANOVA/dispersion और clustering। ये अलग questions के लिए हैं और interchangeable नहीं हैं। Result dataset, taxonomic rank, filtering, transformation, distance, model, covariates और experimental design पर निर्भर करता है।

2. Common workflow#

Scientific parameters बदलने पर analysis दोबारा run करना पड़ता है; visual settings सामान्यतः last result को redraw करते हैं। पुरानी figure visible रह सकती है। DAA, ordination, matrix comparison, networks और clustering के independent local staged filters हैं जो datasets() को नहीं बदलते। PERMANOVA अपने rank/prevalence controls उपयोग करता है। Samples, replicates या taxa कम होने, metadata/tree missing होने, data type गलत होने, model non-estimable होने या package missing होने पर run fail हो सकता है।

3. Differential abundance#

Engines: ANCOM-BC2, LinDA, ALDEx2, corncob और MaAsLin 3। Effect scales अलग हैं: natural log, log2, CLR difference या logit coefficient। Model में main group, reference, covariates और supported engines में random effects हो सकते हैं। Reference बदलने से sign बदलता है। Complete confounding covariate जोड़कर solve नहीं होता। ALDEx2 और corncob random effects support नहीं करते। Methods मुख्यतः count data अपेक्षित करते हैं; proportions, CLR या negative values invalid हो सकते हैं।

4. Multi-engine consensus#

Comparison mode shared prevalence filter लागू करता है ताकि सभी engines same taxa test करें। Consensus adjusted significance और direction compare करता है, magnitude नहीं। corncob dispersion और MaAsLin 3 prevalence अलग outputs हैं और abundance vote में शामिल नहीं होते। Benjamini-Hochberg जैसी consistent correction उपयोग करें और q-value, effect, prevalence, abundance और agreement साथ पढ़ें।

5. Ordinations#

PCA transformed Euclidean matrix summarize करता है; PCoA distance matrix; NMDS distance ranks; CCA/RDA/dbRDA metadata-constrained structure। Raw-count PCA depth और abundant taxa से dominate हो सकता है। PCoA में negative eigenvalues आ सकते हैं। NMDS के लिए stress, convergence, goodness और Shepard diagnostics देखें। DCA gradient length linear बनाम unimodal method चुनने में सहायता कर सकती है।

6. Ordination settings and diagnostics#

Transformations: relative abundance, Hellinger, log1p, CLR, VST। CLR को positive pseudo-count और VST को DESeq2 चाहिए। CLR + Bray problematic है; Aitchison पहले से log-ratio geometry है; Jaccard presence/absence के लिए; UniFrac को matched tree चाहिए। Rarefaction reads हटाती और samples drop कर सकती है। Ellipses और envfit causal tests नहीं हैं। Saved ordinations Procrustes से compare हो सकती हैं।

7. Matrix comparison#

Same biological units पर measured datasets compare करता है। Names या metadata से reliable matching key अनिवार्य है; duplicates analysis invalidate करते हैं। Mantel distance correlation, Procrustes/PROTEST configuration alignment, co-inertia shared axes, और MCOA common-sample intersection से multi-dataset consensus देता है। Overlap, A/B PCoA, alpha, PERMANOVA और Venn/UpSet भी उपलब्ध हैं।

8. Association networks#

Nodes taxa और edges statistical associations हैं, proven interactions नहीं। Preparation aggregation, filtering, normalization और transformation कर सकती है। Methods में CLR correlations, proportionality, SPIEC-EASI, SparCC, gCoda, CCLasso और mixOmics sPLS हैं। Edges weight, q-value और bootstrap stability से filter हो सकती हैं। Hubs/modules hypotheses हैं और abundance या compositional artifacts दर्शा सकते हैं।

9. Network comparison and multi-domain#

Metadata groups के लिए अलग networks बनाकर shared/specific edges, signs, hubs और modules compare किए जा सकते हैं। Unequal group sizes power differences पैदा करते हैं। Multi-domain mode matched 16S/ITS/18S datasets जोड़ता है और केवल common samples रखता है। Outputs interactive graph, domain matrix, Sankey, Chord, edge tables और GraphML हैं। Cross-domain edge direct interaction prove नहीं करती।

10. PERMANOVA and dispersion#

PERMANOVA (adonis2) group centroids और PERMDISP (betadisper) within-group dispersion test करता है। दोनों significant हों तो location effect dispersion से confounded हो सकता है। Model covariates, free formula, permutation blocks, sequential/marginal tests और pairwise शामिल कर सकता है। Sequential result term order पर निर्भर है; marginal R² additive होना जरूरी नहीं। Paired/repeated designs में strata आवश्यक है।

11. Clustering#

Clustering unsupervised है। Transformation और distance similarity define करते हैं। Linkage methods cophenetic correlation से compare होते हैं; incompatible distances पर Ward हटता है। Candidate k silhouette, Dunn, height jumps और cluster sizes से evaluate होता है। Statistically best k biological truth नहीं है। Taxon-wise heatmap scaling absolute abundance differences छिपाती है।

12. Transformations, distances and data type#

Raw counts + Bray absolute abundance, relative + Bray composition, presence/absence + Jaccard shared taxa, CLR/Euclidean या Aitchison log-ratios, UniFrac phylogeny emphasize करते हैं। Metabarcoding data compositional है। Rarefaction, ALDEx2, ANCOM-BC और कई network methods counts अपेक्षित करते हैं। CLR को reads की तरह उपयोग न करें। Pseudo-count log सक्षम करता है, zero का biological meaning तय नहीं करता।

13. Experimental design and interpretation#

Statistics biological replication का substitute नहीं है। Few samples के साथ many covariates unstable model बनाते हैं। Complete confounding effects अलग नहीं होने देता। Interactions को सभी combinations में observations चाहिए। Many taxa tests के लिए q-values आवश्यक हैं। 999 permutations में minimum p लगभग 0.001 है। Effect size, R², stability, prevalence, abundance और ecological plausibility देखें।

14. Histories, exports and reproducibility#

हर submodule explicit save के बाद current project में snapshot लिखता है। Snapshots parameters, results, PNG, RDS, XLSX/TSV, logs और package versions रख सकते हैं। R code export snapshot RDS, versions और seed पर निर्भर हो सकता है। Compatible figures MultiView में जा सकती हैं। GraphML Cytoscape/Gephi में network analysis के लिए उपयोगी है।

15. Performance and dependencies#

Heavy cases: ASV level पर multiple differential engines, NMDS/many permutations, MCOA, bootstrap networks, pairwise PERMANOVA और large clustering matrices। Aggregated ranks से शुरू करें, rare taxa filter करें और engines/contrasts/permutations/network size सीमित रखें। Optional packages में ANCOMBC, ALDEx2, corncob, maaslin3, vegan, ade4, SpiecEasi, propr, gCoda, CCLasso, mixOmics, DESeq2 और openxlsx शामिल हैं। Cancellation non-interruptible unit के बीच ही हो सकती है।

17. Checklists and recommended workflow#

DAA से पहले counts, group, reference, replicates, NA, covariates और random effects verify करें। Ordination/PERMANOVA से पहले transformation-distance साथ चुनें, permutation blocks और diagnostics देखें। Matrix comparison में matching keys/common samples validate करें। Networks में rare taxa limit और stability assess करें। Recommended flow: Description → persistent filtration → descriptive ordination → PERMDISP/PERMANOVA → differential abundance → multi-marker matrix comparison → networks/clustering for hypotheses → tables/figures/code/project save करें।

18. Main limitations and verified sources#

Submodule states independent हैं, figures stale हो सकती हैं, engine effect scales directly comparable नहीं, PERMANOVA dispersion-sensitive है, matrix comparison matching पर निर्भर है, networks causality prove नहीं करते और clustering preparation-sensitive है। Sources modules/analyse/ के main, daa_ancombc, ordination, comparaison_matrices, reseaux_d_association, permanova_dispersion, clustering और _shared/fct_permanova.R में verify किए गए हैं।
