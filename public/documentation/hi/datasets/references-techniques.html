डेटासेट — तकनीकी संदर्भ

इस BarCodeR संस्करण में मौजूद वास्तविक कोड से बनाया गया तकनीकी इन्वेंटरी।

यह पृष्ठ documentation-src/build_docs.py द्वारा दोबारा बनाया जाता है। Function names, identifiers और line numbers वर्तमान source code से आते हैं।

2. आर्किटेक्चर और मुख्य डेटा प्रवाह#

datasets() + active_ds()
  → registry rendering
  → activate / rename / duplicate / reorder / delete
  → unsaved-state marker
  → bcr_save_registry()
  → save/projects/<slug>/registry.rds

project manager
  → manifest + .current pointer
  → save / restore / create / open / rename
  → duplicate / delete
  → ZIP export / import
  → full-session reload on project switch

2.1. Reactive state और memory#

Identifier भूमिका
datasets() Memory में मौजूद phyloseq objects की named reactive list।
active_ds() Application के global reference के रूप में इस्तेमाल dataset का नाम।
vals$persist_project() Current registry को persist करने वाला global callback।
vals$switch_project() Current project बदलकर session reload करने वाला global callback।
proj_tick() Project list और sizes refresh कराने वाला reactive counter।
rv$export_name Individual export के लिए चुना गया dataset।
rv$del_project_slug Deletion confirmation की प्रतीक्षा कर रहा project slug।

2.2. Traceability chains#

row action
  → Shiny input (activate/edit/duplicate/export/reorder/delete)
  → datasets() and/or active_ds() mutation
  → project marked unsaved
  → explicit Save project
  → registry.rds + manifest.rds

Open project
  → attempt to persist current project
  → bcr_write_current_slug()
  → session reload
  → bcr_load_registry() + UI-state restoration

5. Validation और integrity guard#

Layer Function Effect
Dataset name bcr_clean_label() / bcr_make_unique_label() Safe key बनाता है और silent overwrite रोकता है।
Filtered lineage relabel_dataset_parents() Recognized descendants में parent_dataset अपडेट या साफ़ करता है।
Persistence bcr_save_registry() Registry atomically लिखता है और non-empty save को empty memory से बचाता है।
Current project .current + bcr_write_current_slug() अगली startup पर खुलने वाला slug persist करता है।
ZIP archive bcr_find_project_root() registry.rds, manifest.rds या known history folders खोजता है।
Project deletion bcr_delete_project() Current project को अस्वीकार करता है और directory हटने की पुष्टि करता है।
