OpenMetaBar — तकनीकी संदर्भ

इस BarCodeR संस्करण में मौजूद वास्तविक कोड से बनाया गया तकनीकी इन्वेंटरी।

यह पृष्ठ documentation-src/build_docs.py द्वारा दोबारा बनाया जाता है। Function names, identifiers और line numbers वर्तमान source code से आते हैं।

1. स्रोत फ़ाइलें#

भूमिका Path
Interface Shiny modules/openmetabar/mod_openmetabar_ui.R
Serveur, validation, SSH, Slurm, monitoring modules/openmetabar/mod_openmetabar_server.R
Pipeline embarqué modules/openmetabar/nf-openmetabar.tar.gz
Documentation source documentation-src/hi/openmetabar/
Documentation générée www/documentation/hi/openmetabar/

2. आर्किटेक्चर और मुख्य डेटा प्रवाह#

UI OpenMetaBar
  → reactive state cfg / run / steps / caps
  → file validation and staging
  → SSH connection and capability detection
  → Nextflow overlay + Slurm launcher
  → sbatch submission
  → squeue / sacct monitoring
  → remote results and logs
  → phyloseq validation
  → BarCodeR dataset registry
