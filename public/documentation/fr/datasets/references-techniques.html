2. Architecture et flux principaux#

datasets() + active_ds()
  → registry rendering
  → activate / rename / duplicate / reorder / delete
  → unsaved-state marker
  → bcr_save_registry()
  → save/projects/<slug>/registry.rds

project manager
  → manifest + .current pointer
  → save / restore / create / open / rename
  → duplicate / delete
  → ZIP export / import
  → full-session reload on project switch

2.1. État réactif et mémoire#

Identifiant Rôle
datasets() Liste réactive nommée contenant les objets phyloseq actuellement en mémoire.
active_ds() Nom du dataset utilisé comme référence globale dans l’application.
vals$persist_project() Fonction globale appelée pour enregistrer le registre courant.
vals$switch_project() Fonction globale qui écrit le projet courant puis recharge la session.
proj_tick() Compteur réactif forçant le rafraîchissement de la liste et des tailles de projets.
rv$export_name Nom du dataset sélectionné pour l’export individuel.
rv$del_project_slug Slug du projet en attente de confirmation de suppression.

2.2. Chaînes de traçabilité#

row action
  → Shiny input (activate/edit/duplicate/export/reorder/delete)
  → datasets() and/or active_ds() mutation
  → project marked unsaved
  → explicit Save project
  → registry.rds + manifest.rds

Open project
  → attempt to persist current project
  → bcr_write_current_slug()
  → session reload
  → bcr_load_registry() + UI-state restoration

5. Validation et garde d’intégrité#

Couche Fonction Effet
Nom de dataset bcr_clean_label() / bcr_make_unique_label() Produit une clé sûre et évite l’écrasement silencieux.
Parenté filtrée relabel_dataset_parents() Met à jour ou efface parent_dataset dans les descendants reconnus.
Sauvegarde bcr_save_registry() Écrit atomiquement le registre et protège une sauvegarde non vide contre une mémoire vide.
Projet courant .current + bcr_write_current_slug() Persiste le slug qui sera rouvert au prochain démarrage.
Archive ZIP bcr_find_project_root() Recherche registry.rds, manifest.rds ou des dossiers d’historique connus.
Suppression de projet bcr_delete_project() Refuse le projet courant et vérifie la disparition effective du dossier.
