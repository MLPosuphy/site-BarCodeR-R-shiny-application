2. Architecture et flux principaux#

fileInput rds_input
  → read_serialized_input()
  → detect_supported_object_type()
  → pending_obj / pending_type / pending_candidates
  → selection or confirmation modal
  → mt_prepare_loaded_phyloseq()
  → bcr_guard_ps() for a single dataset
  → datasets() registry
  → active_ds()
  → unsaved project state

2.1. État réactif et mémoire#

Identifiant Rôle
pending_obj() Objet chargé en attente de confirmation.
pending_type() Type détecté : dataset ou projet.
pending_file_name() Nom original du fichier téléversé.
pending_object_name() Nom de l’objet choisi dans un fichier RData.
pending_candidates() Objets compatibles trouvés dans un RData multi-objets.
datasets() Registre réactif de tous les datasets du projet BarCodeR courant.
active_ds() Nom du dataset utilisé par défaut dans les modules aval.

2.2. Chaînes de traçabilité#

single phyloseq
  → proposed label
  → add or replace modal
  → mt_prepare_loaded_phyloseq()
  → bcr_guard_ps()
  → datasets(new_registry)
  → active_ds(final_label)
  → detailed cleaning report

project object
  → datasets / ps_registry / list-of-phyloseq extraction
  → clean_project_phyloseq_list()
  → name collision resolution
  → merge or replace datasets()
  → active dataset restoration
  → aggregate restoration report

5. Validation et garde d’intégrité#

Couche Fonction Effet
Fichier sérialisé readRDS() / load() Lit l’objet ; un RData est chargé dans un environnement isolé.
Détection detect_supported_object_type() Reconnaît un phyloseq, un projet datasets/ps_registry ou une liste de phyloseq.
Identifiants d’échantillons sanitize_sample_names() Translittère, remplace les caractères non sûrs et résout les doublons.
Cellules metadata vides replace_empty_metadata_with_na() Convertit les colonnes en caractères puis remplace les chaînes vides par NA.
Structure phyloseq bcr_guard_ps() Exige un phyloseq avec OTU table et vérifie les identifiants échantillons/taxons.
Nom du dataset bcr_clean_label() / bcr_make_unique_label() Produit une clé sûre et unique dans le registre.
