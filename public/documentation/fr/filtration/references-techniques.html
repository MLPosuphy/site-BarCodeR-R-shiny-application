2. Architecture et flux principaux#

datasets() + active_ds()
  → selected_ds_filtration
  → reactive block parameters
  → ps_filtered()
      taxonomy
      → abundance
      → samples
      → sequences
  → filtration_log
  → temporary result

temporary filtered phyloseq
  → save name normalization
  → optional overwrite confirmation
  → bcr_guard_ps()
  → add_dataset() / datasets()
  → active_ds()
  → explicit project save in Datasets

2.1. État réactif et mémoire#

Identifiant Rôle
selected_ds_filtration Dataset parent synchronisé avec active_ds().
ps_filtered() Objet phyloseq temporaire recalculé automatiquement à chaque paramètre actif.
advanced_conditions Liste réactive des conditions metadata combinées par ET.
filtration_log Attribut du résultat contenant dimensions, textes, paramètres et éléments supprimés.
pending_overwrite_name Nom nettoyé en attente de confirmation avant écrasement d’un autre dataset.
datasets() / active_ds() Registre global mis à jour uniquement lors de l’enregistrement.

2.2. Validation et garde d’intégrité#

Couche Fonction Effet
Ordre fixe ps_filtered() Applique taxonomie → abondance → échantillons → séquences en un seul passage.
Protection taxons safe_prune_taxa() Refuse une étape qui supprimerait tous les taxons.
Protection échantillons safe_prune_samples() Refuse une étape qui supprimerait tous les échantillons.
Séquences get_refseq_aligned() Aligne les RefSeq et conserve sans test les ASV non couvertes en cas de couverture partielle.
Traçabilité filtration_log$params Stocke les paramètres structurés indépendamment des textes localisés.
Enregistrement sous-module io Ajoute ou écrase datasets(); un nom vide remplace le parent.
Intégrité bcr_guard_ps() Vérifie OTU, échantillons et taxonomie avant insertion dans le registre.
