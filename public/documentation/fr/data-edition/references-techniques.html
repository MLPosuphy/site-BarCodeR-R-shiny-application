2. Architecture et flux principaux#

datasets() + active_ds()
  → selected_dataset
  → metadata / OTU / taxonomy local editor state
  → immediate apply to the phyloseq object
  → datasets() replacement
  → edit_log append
  → explicit project save in Datasets

full component import
  → fileInput selection
  → identifier and coverage checks
  → slot replacement
  → local editors must be refreshed

2.1. État réactif et mémoire#

Identifiant Rôle
selected_dataset Dataset édité et synchronisé avec active_ds().
edit_log Attribut du phyloseq contenant la trace descriptive des opérations.
initial_data / previous_data États locaux utilisés par Réinitialiser et Annuler dans chaque sous-module.
tax_edit_info_seen Indique si l'avertissement préalable à l'édition taxonomique a été affiché.
replacement_preview Inventaire des cellules taxonomiques correspondant aux motifs de remplacement.
pending_save_label Nom nettoyé en attente de confirmation avant écrasement d'un autre dataset.

2.2. Chaînes de traçabilité#

cell / structure action
  → capture previous local state
  → rebuild sample_data / otu_table / tax_table
  → update datasets()[selected_dataset]
  → append edit_log
  → mark project unsaved

Save under another name
  → edited source already changed
  → copy current edited state to a new registry key
  → new key becomes active
  → project still requires explicit disk save

5. Validation et garde d’intégrité#

Contrôle Fonction Effet
Synchronisation active bcr_bind_active_picker() Relie le sélecteur Data Edition au dataset actif global.
Application immédiate fonctions apply_*() Réécrit le composant phyloseq et datasets() dès chaque action.
Historique add_edit_log() Ajoute une trace descriptive, sans snapshot complet de l'ancien objet.
OTU numérique conversion matrix/numeric Les valeurs non convertibles deviennent NA avec avertissement.
RefSeq / arbre réalignement après OTU Réordonne ou supprime le composant lorsqu'il ne couvre plus tous les taxons.
Import complet handlers fileInput Remplace le slot sélectionné dès le choix du fichier, sans prévisualisation générale.
Enregistrement save_to_registry Copie ou écrase une entrée du registre ; ne persiste pas le projet sur disque.
