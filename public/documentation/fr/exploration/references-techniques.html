2. Architecture et flux principaux#

datasets() + active_ds()
  → six independent Exploration submodules
  → optional local staged filtering
  → scientific calculation + dirty tracking
  → visual rendering
  → tables / logs / reproducible code
  → project-specific history snapshots

2.1. État réactif et mémoire#

Identifiant Rôle
Sélecteurs locaux Suivent active_ds() en mode follow-only pour plusieurs sous-modules.
Filtrations locales États temporaires indépendants pour Barplot, Alpha, Venn, Heat Tree et Qualité taxonomique.
Dirty tracking Sépare les paramètres scientifiques nécessitant un recalcul des réglages visuels.
Historiques Chaque outil écrit ses snapshots, paramètres et exports dans son dossier de projet.

2.2. Main analytical flows#

Tool Flow
Barplot phyloseq → taxonomy aggregation → composition → rendering → targeted test
Alpha datasets → indices / rarefaction → plots → statistics
Venn / UpSet datasets or groups → sets → intersections → annotations
Heat Tree taxonomy → descriptive metrics or ANCOM-BC → taxonomic tree
Phylo Tree phy_tree + OTU → pruning → rendering + Faith PD
Taxonomic Quality tax_table + reads → assignment by rank and strict depth
