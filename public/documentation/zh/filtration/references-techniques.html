2. 架构与主要数据流#

datasets() + active_ds()
  → selected_ds_filtration
  → reactive block parameters
  → ps_filtered()
      taxonomy
      → abundance
      → samples
      → sequences
  → filtration_log
  → temporary result

temporary filtered phyloseq
  → save name normalization
  → optional overwrite confirmation
  → bcr_guard_ps()
  → add_dataset() / datasets()
  → active_ds()
  → explicit project save in Datasets

2.1. 反应式状态与内存#

标识符 作用
selected_ds_filtration 与 active_ds() 同步的父数据集。
ps_filtered() 每个活动参数变化时自动重算的临时 phyloseq。
advanced_conditions 使用 AND 组合的元数据条件反应式列表。
filtration_log 保存维度、文本、参数和删除元素的结果属性。
pending_overwrite_name 等待覆盖确认的规范化名称。
datasets() / active_ds() 仅在保存结果时更新的全局注册表。

2.2. 验证与完整性保护#

层 函数 作用
固定顺序 ps_filtered() 单次执行分类 → 丰度 → 样本 → 序列。
分类单元保护 safe_prune_taxa() 拒绝会删除全部分类单元的步骤。
样本保护 safe_prune_samples() 拒绝会删除全部样本的步骤。
序列 get_refseq_aligned() 对齐 RefSeq；部分覆盖时未覆盖 ASV 保留且不检测。
可追溯性 filtration_log$params 独立于本地化文本保存结构化参数。
保存 io 子模块 添加或覆盖 datasets()；空名称替换父数据集。
完整性 bcr_guard_ps() 写入前检查 OTU、样本和分类一致性。
