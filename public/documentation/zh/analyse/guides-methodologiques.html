分析 — 方法指南

1. 作用与结构#

分析页包含六类方法：差异丰度、排序、矩阵比较、关联网络、PERMANOVA/离散度和聚类。它们回答不同问题，不能互换。结果由数据集、分类层级、过滤、转换、距离、模型、协变量和实验设计共同决定。

2. 通用运行方式#

科学参数改变后必须重新计算；视觉参数通常只重绘上一次结果。旧图可能继续显示，因此需要检查“需要重新计算”。差异分析、排序、矩阵比较、网络和聚类各自具有独立的临时过滤状态，不会修改 datasets()。PERMANOVA 使用自己的层级和流行度设置。样本、重复或分类单元不足，metadata/树缺失，数据类型错误，模型不可估计或依赖包缺失都会使分析失败。

3. 差异丰度分析#

可用引擎：ANCOM-BC2、LinDA、ALDEx2、corncob 和 MaAsLin 3。效应单位不同：自然对数、log2、CLR 差异或 logit 系数。模型可包含主因素、参考水平、协变量以及部分引擎支持的随机效应。更改参考水平会反转效应方向。完全混杂不能通过添加协变量解决。ALDEx2 和 corncob 不支持随机效应。大多数方法要求计数数据；比例、CLR、负值或已转换矩阵可能无效。

4. 多引擎共识#

比较模式使用统一的流行度过滤，使所有引擎检验同一批分类单元。共识只比较校正后的显著性和效应方向，不比较效应幅度。corncob 的离散度和 MaAsLin 3 的出现率是独立问题，不参与丰度共识。通常使用 Benjamini-Hochberg 校正，并同时查看 q 值、效应、流行度、丰度和方法一致性。

5. 排序方法#

PCA 总结欧氏转换矩阵；PCoA 表示距离矩阵；NMDS 保留距离排序；CCA、RDA 和 dbRDA 使用 metadata 约束群落结构。原始计数 PCA 常被测序深度和高丰度分类单元主导。非欧氏距离的 PCoA 可能出现负特征值。NMDS 必须检查 stress、收敛、goodness 和 Shepard 图。DCA 梯度长度可帮助在线性和单峰方法之间选择。

6. 排序参数与诊断#

转换包括相对丰度、Hellinger、log1p、CLR 和 VST。CLR 需要正伪计数，VST 需要 DESeq2。不是所有组合都合理：CLR + Bray-Curtis 有问题；Aitchison 已包含 log-ratio；Jaccard 适合存在/缺失；UniFrac 需要匹配的系统发育树。稀释会丢失 reads 并可能删除样本。椭圆和 envfit 向量只是辅助解释，不证明因果。保存的排序可用 Procrustes 比较。

7. 矩阵比较#

用于比较在同一生物单位上测得的多个数据集。必须通过名称或 metadata 构建可靠匹配键；重复或模糊键会使分析无效。Mantel 比较距离矩阵；Procrustes/PROTEST 对齐排序并识别大残差样本；协惯量寻找共同轴；MCOA 使用共有样本交集构建多数据集共识。还提供样本/分类重叠、A/B PCoA、alpha 多样性、PERMANOVA 和 Venn/UpSet。

8. 关联网络#

节点代表分类单元，边代表统计关联，不是已证明的生态互作。准备步骤可聚合、过滤、标准化和转换。方法包括 CLR 相关、比例性、SPIEC-EASI、SparCC、gCoda、CCLasso 和 mixOmics sPLS。边可按权重、q 值和 bootstrap 稳定性过滤。hub 和模块只能作为假设，可能受丰度、分组结构或组成效应影响。

9. 网络比较与多域网络#

可以按 metadata 组分别推断网络并比较共有/特异边、符号、hub 和模块。组间样本量不平衡会造成统计功效差异。多域模式组合配对的 16S、ITS、18S 等数据集，只保留共有样本。输出包括交互网络、域交互矩阵、Sankey、Chord、边表和 GraphML。跨域边不证明直接生物互作。

10. PERMANOVA 与离散度#

PERMANOVA (adonis2) 检验组中心差异；PERMDISP (betadisper) 检验组内离散度差异。两者都显著时，PERMANOVA 可能受离散度混杂。模型可包含协变量、自由公式、置换块、顺序/边际检验和 pairwise。顺序检验依赖项顺序；边际 R² 不一定可加。配对或重复设计必须使用 strata 限制置换。

11. 聚类#

聚类是无监督的，可聚类样本、分类单元或两者。转换和距离定义相似性。层次聚类方法通过 cophenetic 相关比较；不兼容距离时排除 Ward。候选 k 可用 silhouette、Dunn、树高跳跃和簇大小评估。统计上最优的 k 不一定有生物意义。按分类单元缩放 heatmap 会隐藏绝对丰度差异。

12. 转换、距离与数据类型#

原始计数 + Bray 强调绝对丰度；相对丰度 + Bray 强调组成；存在/缺失 + Jaccard 强调共享分类单元；CLR/欧氏或 Aitchison 强调 log-ratio；UniFrac 强调系统发育。宏条形码数据具有组成性。稀释、ALDEx2、ANCOM-BC 和多种网络方法要求计数。不能把 CLR 当作 reads。伪计数只解决对数计算，不决定零值的生物意义。

13. 实验设计与解释#

统计方法不能替代生物重复。样本少而协变量多会导致不稳定模型。完全混杂无法分离效应。交互项需要各组合都有观测。大量分类单元检验必须使用 q 值。999 次置换的最小 p 值约为 0.001。需要结合效应量、R²、稳定性、流行度、丰度和生态合理性。

14. 历史记录、导出与可复现性#

每个子模块只有在明确保存后才写入当前项目的快照。快照可包含参数、结果、PNG、RDS、XLSX/TSV、日志和包版本。R 代码导出尝试复现保存结果，可能依赖快照 RDS、包版本和随机种子。兼容图可进入 MultiView。GraphML 可用于 Cytoscape 或 Gephi。

15. 性能与依赖#

高成本情况包括 ASV 层级多引擎差异分析、NMDS 和大量置换、MCOA、bootstrap 网络、pairwise PERMANOVA 和大矩阵聚类。先使用聚合层级、过滤稀有分类单元并限制引擎、对比、置换和网络规模。可选包包括 ANCOMBC、ALDEx2、corncob、maaslin3、vegan、ade4、SpiecEasi、propr、gCoda、CCLasso、mixOmics、DESeq2 和 openxlsx。取消操作可能只能在不可中断单元之间生效。

16. 常见问题#

现象 原因 处理
图是旧结果 未重新计算 重新运行
引擎被跳过 包/数据/模型不兼容 查看日志
CLR + Bray 警告 几何不合理 使用 Aitchison/欧氏
UniFrac 不可用 树缺失或不匹配 检查叶节点
共有样本很少 匹配键错误 检查重复和名称清理
网络过密/过空 阈值或功效问题 调整过滤
PERMANOVA 与 PERMDISP 都显著 离散度混杂 谨慎解释
Ward 不可用 距离不兼容 更换距离或连接方法

17. 检查清单与推荐流程#

差异分析前检查计数、组、参考、重复、NA、协变量和随机效应。排序/PERMANOVA 前联合选择转换与距离，设置置换块并检查 stress、特征值和离散度。矩阵比较前验证匹配键和共有样本。网络前限制稀有分类单元并评估稳定性。推荐顺序：Description → 持久过滤 → 描述性排序 → PERMDISP/PERMANOVA → 差异分析 → 多标记矩阵比较 → 网络/聚类生成假设 → 保存表、图、代码和项目。

18. 主要限制与验证来源#

各子模块状态独立，图可能过期，引擎效应尺度不可直接比较，PERMANOVA 受离散度影响，矩阵比较完全依赖匹配，网络不证明因果，聚类高度依赖数据准备。来源已在 modules/analyse/ 的主模块、daa_ancombc、ordination、comparaison_matrices、reseaux_d_association、permanova_dispersion、clustering 和 _shared/fct_permanova.R 中核对。
