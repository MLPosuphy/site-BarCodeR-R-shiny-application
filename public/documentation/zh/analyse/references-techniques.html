2. 架构与主要数据流#

datasets() + metadata + optional phy_tree
  → six independent Analysis submodules
  → optional local staged filtering
  → scientific computation / permutations / model engines
  → diagnostics + tables + figures
  → project-specific snapshots and reproducible code

2.1. 反应式状态与内存#

标识符 作用
本地选择 每个子模块保留自己的数据集、科学参数和显示状态。
本地过滤 差异分析、排序、矩阵比较、网络和聚类使用彼此独立的临时过滤状态。
高成本计算 差异分析引擎、NMDS、置换、MCOA 和网络可提供进度与取消。
历史记录 结果、图形、表格和可复现脚本保存到当前项目。

2.2. Main analytical flows#

Tool Flow
Differential abundance phyloseq → shared filtering → engine(s) → corrected results → consensus / figures
Ordination phyloseq → transformation + distance → ordination → diagnostics / overlays
Matrix comparison datasets → sample matching → distance / ordination → Mantel, Procrustes, co-inertia or MCOA
Association networks taxon matrix → compositional preparation → inference → robustness → graph diagnostics
PERMANOVA distance + metadata model → adonis2 + betadisper → combined verdict
Clustering transformation + distance → linkage comparison → k diagnostics → dendrogram / heatmap
