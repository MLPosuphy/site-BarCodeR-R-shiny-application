2. 架构与主要数据流#

datasets() + active_ds()
  → selected_dataset
  → metadata / OTU / taxonomy local editor state
  → immediate apply to the phyloseq object
  → datasets() replacement
  → edit_log append
  → explicit project save in Datasets

full component import
  → fileInput selection
  → identifier and coverage checks
  → slot replacement
  → local editors must be refreshed

2.1. 反应式状态与内存#

标识符 作用
selected_dataset 正在编辑并与 active_ds() 同步的数据集。
edit_log phyloseq 属性，用于保存操作的描述性审计记录。
initial_data / previous_data 各子模块中重置和撤销所使用的本地状态。
tax_edit_info_seen 记录是否已经显示分类编辑警告。
replacement_preview 与替换模式匹配的分类单元格清单。
pending_save_label 等待覆盖确认的清理后名称。

2.2. 可追溯链#

cell / structure action
  → capture previous local state
  → rebuild sample_data / otu_table / tax_table
  → update datasets()[selected_dataset]
  → append edit_log
  → mark project unsaved

Save under another name
  → edited source already changed
  → copy current edited state to a new registry key
  → new key becomes active
  → project still requires explicit disk save

5. 验证与完整性保护#

控制 函数 作用
活动数据集同步 bcr_bind_active_picker() 将 Data Edition 选择器连接到全局活动数据集。
立即应用 apply_*() 函数 每次操作都会重写 phyloseq 组件和 datasets()。
审计记录 add_edit_log() 添加描述性记录，但不保存旧对象的完整快照。
OTU 数值化 matrix/numeric 转换 无法转换的值变为 NA，并生成警告。
RefSeq / 树 OTU 修改后重新对齐 若无法覆盖全部分类单元，则重排或删除该组件。
完整导入 fileInput handlers 选择文件后立即替换对应 slot，不提供统一预览。
注册表保存 save_to_registry 复制或覆盖注册表条目；不会把项目持久化到磁盘。
