2. 架构与主要数据流#

datasets() + active_ds()
  → selected_dataset_single
  → phyloseq extraction and temporary OTU orientation
  → sample / ASV / sequence / completeness metrics
  → Plotly and DT outputs
  → optional vegan::rarefy() computation

all in-memory datasets
  → compute_dataset_stats()
  → selected comparison subset
  → normalized heatmap / dotplot / baseline delta
  → filtration-log comparison

2.1. 反应式状态与内存#

标识符 作用
selected_dataset_single 当前检查的数据集，并与 active_ds() 同步。

project_baseline_dataset 计算相对差异时使用的参考数据集。

2.2. 可追溯链#

selected dataset
  → active_ds() synchronization
  → compute_dataset_stats() + sample/asv metrics
  → diagnostic cards and interactive plots
  → tables / CSV exports

Calculate curves
  → positive-count and ≥50-read checks
  → vegan::rarefy() on up to ~80 depths
  → cached rarefaction_result
  → individual or pooled-group rendering

5. 验证与完整性保护#

控制 函数 作用
OTU 方向 get_otu_taxa_rows() 仅转置计算矩阵，不修改 phyloseq 对象。
分组 get_group_var_choices() 仅保留具有 2–15 个非缺失水平的非时间变量。
异常值 iqr_outlier_flag() / iqr_distance_score() 对 reads、丰富度和优势度执行全局 1.5 IQR 检测。
稀释曲线 vegan::rarefy() 要求兼容的计数，并排除少于 50 reads 的样本。
表格 get_table_*_df() 仅为显示和导出添加 ASV/SampleID 并安全化名称。
项目视图 compute_dataset_stats() 跨数据集求和，不对样本或分类单元去重。
