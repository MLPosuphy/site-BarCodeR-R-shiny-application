描述 — 方法指南

1. 总体介绍#

描述（Description）选项卡用于在编辑、过滤或统计分析之前，检查 BarCodeR 中 phyloseq 对象的结构与内容。

它分为两个互补视图。

数据集视图#

一次检查一个 phyloseq 对象，可用于：

  • 检查维度和可用组件；
  • 查看描述性指标；
  • 可视化丰度和观测丰富度；
  • 检查参考序列；
  • 计算稀释曲线；
  • 识别异常样本；
  • 查看和导出表格；
  • 查看过滤日志；
  • 阅读 OpenMetaBar 来源信息。

项目视图#

比较当前内存中的多个数据集，可用于汇总、选择和比较其维度、测序深度、丰富度、稀疏度、相对参考数据集的差异，以及过滤日志中的删除情况。

2. 该选项卡的作用#

描述选项卡主要用于理解数据、检查导入结果、发现明显异常、为后续方法选择做准备，以及比较多个数据集的一般结构。

需求 应使用的选项卡
修改表格 Data Edition
删除样本或分类单元 Filtration
重命名或删除数据集 Datasets
进行统计分析 Analysis
从 FASTQ 启动流程 OpenMetaBar

3. 对数据的影响#

描述选项卡不会修改 OTU table、分类表、metadata、序列、系统发育树、丰度、标识符或日志。图表和表格基于当前内存中的对象生成。

3.1. 例外：活动数据集#

数据集视图的主选择器与全局活动数据集同步。更换数据集会更新 active_ds()，影响 BarCodeR 其他模块使用的默认数据集，并可能将项目标记为未保存。

phyloseq 内容本身不变，但全局工作上下文会改变。

4. 必要条件#

大多数功能至少需要 otu_table。

以下组件可选：

  • sample_data；
  • tax_table；
  • refseq；
  • 系统发育树；
  • 来源属性；
  • 过滤日志。

缺少组件会减少可用信息，但不一定阻止打开该选项卡。

5. 关于丰度值的重要假设#

模块将 OTU table 中的值称为 reads，但不会验证它们是否为原始、整数、未转换且非负的计数。

如果对象包含相对丰度、CLR 或对数转换、归一化值、小数或负值，则“reads”不再表示原始测序深度。

这会直接影响总和、丰富度、优势度、稀释曲线和数据集比较的解释。

7. 选择数据集#

选择数据集字段包含当前会话中的所有数据集。

7.1. 全局同步#

它跟随全局活动数据集。在 Datasets、侧边栏或其他全局选择器中更改时，描述选项卡会同步；反过来，在描述中更改也会改变应用的活动数据集。

7.2. 回退值#

若没有有效活动数据集，则使用之前选择且仍存在的数据集，否则使用列表中的第一个。

7.3. 更换数据集#

更换后会重新计算指标、图表、表格、分组选项、来源和异常值。

稀释曲线注意：数据集更换后不会自动重新计算稀释曲线，必须再次点击计算曲线。

8. 分组变量#

分组变量 — 样本使用 sample_data 的某一列对样本着色或分组。

8.1. 可选变量#

仅提供具有 2–15 个非缺失不同值的列，并排除 Date、POSIXct、POSIXt。

8.2. 数值列#

若数值列仅有 2–15 个不同值，也会作为分类变量提供。例如 10, 15, 20 会被视为三个组，而不是连续变量。

8.3. 缺失值#

缺失值统一显示为 NA。文本 "NA" 与真正缺失值可能难以区分。

8.4. 不分组#

选择不分组时，所有样本归入一个名为 全部 的组。

8.5. 分组的作用#

分组影响颜色、组间小提琴图、累计曲线、稀释曲线、异常值上下文和组内异常比例，但不修改数据。

9. 分组不会改变异常值检测#

异常值阈值基于整个数据集计算，而不是在每个组内分别计算。

分组仅用于解释和着色。因此，某个样本可能在本组内正常，但相对整个数据集被标记为异常。

10. “查看日志”按钮#

该按钮选择“表格与日志”中的过滤日志子选项卡。

当前实现不会自动滚动页面，也不一定展开折叠框。点击后可能需要手动滚动并展开该区域。

11. 数据集标题#

标题显示数据集名称、样本数、分类单元数、总丰度和可用组件。

130 个样本 • 2 450 个 ASV/OTU • 7 779 736 reads

12. 组件徽章#

徽章表示 OTU table、分类表、metadata、参考序列和过滤日志是否存在。

12.1. OTU#

表示检测到 otu_table。

12.2. 分类信息#

表示存在 tax_table，但不保证所有 ASV 已注释、所有层级完整或分类结果正确。

12.3. Metadata#

表示存在 sample_data，但不保证变量可用、类型正确或无缺失值。

12.4. RefSeq#

表示参考序列存在且 Biostrings 可读取。若缺少 Biostrings，即使对象含有 refseq，也可能显示为缺失。

12.5. 日志#

表示存在 filtration_log 属性，但不保证其中真的有删除记录。

12.6. 系统发育树#

当前没有专用树徽章，因此不能据此判断 phy_tree 是否存在。

13. OTU table 方向#

描述模块会临时将矩阵调整为分类单元在行、样本在列。若原对象相反，只在计算内存中转置，不修改原始 phyloseq。

14. 指标：分类单元数量#

等同于 phyloseq::ntaxa(ps)。界面使用 ASV 一词，但实际单位可能是 ASV、OTU、ZOTU 或其他单位。

15. 指标：样本数量#

等同于 phyloseq::nsamples(ps)。

16. 指标：总 reads#

为 OTU table 所有单元格之和，忽略缺失值。只有矩阵为原始计数时，才可解释为总 reads。

17. 指标：每个样本的 reads#

Reads = 该样本所有分类单元丰度之和

随后计算最小值、最大值、均值、中位数和标准差，主卡片显示中位数。

18. 指标：观测丰富度#

丰富度 = 丰度严格大于零的分类单元数量

这是原始观测丰富度，不是 Chao1、ACE、Shannon、Simpson，也未校正测序深度。

19. 指标：最大优势分类单元的占比#

优势度 (%) =
最大分类单元丰度
÷ 样本总丰度
× 100

高优势度可能来自真实生物学、偏好扩增、污染、组成失衡或低深度，不能单独判定质量差。

20. 指标：每个样本的零值比例#

零值 (%) =
丰度为零的分类单元数量
÷ 分类单元总数
× 100

该指标目前不参与异常值判定。

21. 指标：全局稀疏度#

零值单元格数
÷ OTU table 总单元格数
× 100

21.1. 解释#

代谢条形码数据常因多样性、分类单元专一性、空间差异、检测限制、深度和流程处理而高度稀疏。

21.2. 显示阈值#

稀疏度 提示
≥ 97% 非常高
90–<97% 高
<90% 可控

这些只是内部显示规则，不是通用科学标准。

21.3. NA 的影响#

NA 不计为零，但仍留在分母中，因此可能轻微低估稀疏度。

22. 深度变异性#

CV (%) =
样本 reads 标准差
÷ 样本 reads 均值
× 100

当 CV ≥ 100% 时显示深度非常不均一。该阈值仅为内部描述规则。

23. 分类完整性#

完整性 (%) =
非缺失且非空的值
÷ ASV 总数
× 100

显示的平均完整性是各分类层级百分比的非加权平均。

23.1. 后果#

平均值可能掩盖某些层级很完整、另一些层级很缺失的情况，应查看详细表格。

23.2. 仅含空格的字符串#

若导入前未清理，可能被视为已填写。

24. Metadata 缺失值#

缺失 (%) =
NA 或空字符串数量
÷ 样本数量
× 100

显示的是各变量缺失率的非加权平均。

24.1. "NA" 文本#

文本 "NA" 不是真正的缺失值，可能被计为一个水平。

24.2. 空格#

仅含空格的字符串可能被视为非缺失。

24.3. 显示类型#

表格显示列的第一个 R 类，如 character、numeric、factor、Date，可用于发现导入后变成文本的列。

25. 序列长度#

当 refseq 和 Biostrings 可用时，计算最小、最大、均值、中位数和标准差，单位为 bp。

25.1. 解释#

多峰或范围很宽可能表示多个扩增区域、多个标记、截短序列、indel、非特异产物、过滤不足或真实生物差异。

26. GC 百分比#

GC (%) =
G + C
÷ A + C + G + T
× 100

模糊碱基不进入 ACGT 分母，因此 GC 可能只基于序列的非模糊部分。

27. 序列名称#

使用 refseq 中的名称。若无有效名称，则生成：

ASV_1
ASV_2
ASV_3

模块不会全面验证序列名是否与 OTU table 分类单元对应。

28. 自动解释信息#

摘要卡根据 reads 中位数、丰富度中位数、稀疏度和组件存在情况生成文字。

它只是描述性帮助，不是科学验证、最终质量控制、过滤决策或统计建议。

29. 数据集快速阅读#

29.1. 结构#

reads 中位数、丰富度中位数和稀疏度。

29.2. 可用内容#

OTU table、分类信息、metadata 和序列是否存在。

29.3. 序列#

若可用，显示长度中位数和 GC 中位数。

29.4. 过滤#

若存在 filtration_log，显示删除的 ASV 和样本数。

30. 自动诊断#

可能提示高稀疏度、深度不均、缺少 metadata、分类信息、序列或存在过滤历史。

这些提示不会修改数据，也不应单独用于排除数据。

31. OpenMetaBar 来源#

该框读取 attr(ps, "openmetabar_run")，不会连接集群。这是导入 phyloseq 时保存的快照。

31.1. Run 摘要#

可包括 ID、标签、日期、技术、标记、引擎、数据库、design file、样本和 FASTQ 数量。

31.2. 拆分样本#

可包括 MiniBar 是否启用、方法和容错参数。

31.3. 过滤器#

可包括方向、质量、长度、编码过滤和遗传密码表。

31.4. LotuS3#

可包括平台、扩增子类型、聚类和分类赋值。

31.5. LCA#

可包括覆盖度、相似性阈值、共识比例和模式。

31.6. IDMABIO#

仅在使用该路线时存在。

31.7. NextITS#

仅在使用该路线时存在。

31.8. 集群环境#

可包括分区、内存、CPU、模块和远程路径。

31.9. FASTQ 文件#

显示的是记录的来源路径，不保证文件仍可访问。

31.10. 样本重命名#

可保留原名称、修正名称、日期和原因。

31.11. 缺少来源信息#

不代表数据集从未由 OpenMetaBar 生成；属性可能在转换、旧版本或外部导出中丢失。

32. 交互式可视化 — 总览#

包括 reads 与丰富度、样本卡、前 15 个样本、前 15 个分类单元以及样本和分类单元累计贡献。

33. Reads 与丰富度#

X = 总丰度
Y = 观测丰富度

颜色表示组，形状表示标准或异常。

33.1. 解释#

可查看深度—丰富度关系、低深度样本和偏离主群的点。

33.2. 限制#

正相关不能证明深度是生物差异的唯一原因。

33.3. 交互#

点击点会更新样本卡。

34. 样本详情卡#

显示 SampleID、reads、丰富度、优势度、零值比例、状态和最多六个 metadata 值。

34.1. 初始样本#

优先显示第一个异常样本，否则显示第一个样本。

34.2. 显示的 metadata#

完全缺失的列被排除，仅显示前六个可用字段，因此并不完整。

35. 前 15 个样本#

按总丰度排序，最多显示 15 个。点击柱形会更新样本卡。

35.1. 限制#

深度最高的样本不一定最好、最丰富或最具代表性。

36. 前 15 个分类单元#

按所有样本的总丰度排序，并在提示中显示出现样本数和比例。

36.1. 出现率#

出现率 = 丰度 > 0 的样本数

36.2. 限制#

使用分类单元 ID 而不是分类注释。仅在一个样本中非常高的 ASV 也可能排在前列。

37. 样本累计贡献#

按丰度降序排列样本，显示前若干样本解释的累计丰度比例。初始陡升表示深度集中于少数样本。

38. 分类单元累计贡献#

显示优势分类单元解释的累计丰度，不考虑分类、出现率、分组或生物学稀有性。

39. 丰度选项卡#

包括 reads 直方图、按组小提琴图和按组累计 reads 曲线。

40. Reads 直方图#

描述每个样本总丰度分布，可发现偏态、过浅或过深样本和多个深度群体。分箱由 Plotly 自动确定。

41. 按组的 reads#

当有多个组时显示小提琴图，包括分布、箱线图、均值和单个点。

41.1. 无分组#

若无可用定性变量，则显示提示。

41.2. 解释#

该图仅为描述性，不进行统计检验、归一化、组大小或协变量校正。

42. 按组累计 reads 贡献#

每组内部按丰度排序并计算累计比例，因此每条曲线都达到 100%。

42.1. 后果#

它描述组内深度集中程度，而不是各组占项目总 reads 的比例。大小不同的组都达到 100%。

43. 丰富度选项卡#

包括丰富度直方图、按组丰富度和丰富度—优势度关系。

44. 丰富度直方图#

显示每个样本观测分类单元数的分布。未校正深度，因此深度更高的样本可能自然观察到更多分类单元。

45. 按组丰富度#

小提琴图比较各组观测丰富度，仅为描述性，不进行统计检验。

46. 丰富度与优势度#

X = 观测丰富度
Y = 最大优势分类单元比例

可区分丰富且均匀、丰富但被优势分类单元主导、贫乏且被主导或其他异常模式。

46.1. 这不是均匀度指数#

最大优势度不等同于 Pielou、Shannon 或 Simpson。最大优势度相同的群落，其余分类单元分布可能完全不同。

47. 序列选项卡#

包括长度直方图、GC 直方图和长度—GC 关系。需要 refseq 和 Biostrings。

48. 长度与 GC#

每个点代表一条序列，可发现不同长度/组成的群体、极端序列或多个标记，但不能单独证明污染或错误。

49. 稀释曲线#

该子选项卡执行独立计算，不会在打开时自动运行。必须点击计算曲线。

50. 使用的稀释方法#

使用：

vegan::rarefy()

它计算给定深度下观测分类单元数量的解析期望值。它不是重复随机抽样，不创建新 phyloseq，不调用 rarefy_even_depth()，不替换丰度，也不保存归一化结果。

51. 稀释计算条件#

需要 vegan、OTU table、至少两个正丰度样本，以及至少两个 reads ≥ 50 的样本。少于 50 reads 的样本被排除。

51.1. 50 reads 阈值#

该阈值写在代码中，目前无法在界面更改，也不是通用标准。

52. 稀释所需数据类型#

vegan::rarefy() 面向计数数据。相对丰度、CLR、负值、连续转换或非整数数据不适合。模块不会阻止所有不适当情况，计算前必须确认 OTU table 的性质。

53. 计算深度#

最多生成约 80 个深度，从 1 到观测最大值。对每个样本，仅保留不超过其总深度的值，并进行取整和去重。

54. 单样本曲线#

按组着色的单样本曲线模式每个样本一条线。提示信息包含 SampleID、组、总 reads、稀释深度、期望/观测丰富度和异常状态。

55. 单样本曲线子集#

选项包括全部样本、Top reads、Bottom reads 和异常值。

55.1. 全部样本#

显示所有符合条件的曲线。当前实现不应用“最大曲线数”，因此样本很多时图形可能很重。

55.2. Top reads#

保留深度最高的样本，数量不超过所选上限。

55.3. Bottom reads#

保留 reads ≥ 50 的样本中深度最低者。

55.4. 异常值#

仅保留 IQR 规则标记的样本。若无异常值，图可能为空。

56. 最大曲线数#

取值范围 2–200。适用于 Top、Bottom 和异常值，但目前不适用于全部样本。

57. 按组聚合曲线#

将同组所有样本的丰度相加，然后对合并群落计算一条曲线。

57.1. 曲线表示什么#

表示该组 reads 池中的期望丰富度，不是单样本曲线平均、每样本平均丰富度或置信区间。

57.2. 组大小影响#

样本数或 reads 更多的组拥有更大池，可能达到更高丰富度。解释时需同时查看组内样本数和总 reads。

57.3. 无分组#

所有样本合并为一条名为 全部 的曲线。

58. 显示图例#

默认关闭。组很多时开启图例可能降低可读性。单样本曲线每组只显示一个图例项。

59. 必须重新计算#

稀释结果属于点击按钮时的活动数据集。更换数据集不会自动重新计算。

59.1. 更改分组变量#

可基于已有结果更新颜色或聚合。

59.2. 旧结果风险#

更换数据集后若未重算，缓存结果可能仍来自前一个数据集。应始终重新计算。

60. 稀释曲线解释#

曲线趋平表示新增 reads 带来的新分类单元逐渐减少；持续上升表示增加深度可能发现更多分类单元。

没有平台并不一定表示质量差或测序不足，也可能来自极高多样性、稀有分类单元、残余噪声、测序错误或真实异质性。

61. 稀释曲线的限制#

不提供置信区间、重复随机抽样均值、外推、Good 覆盖度、Chao1、曲线间统计比较或自动饱和阈值。它只是描述工具。

62. 异常值检测#

基于三个指标：深度、丰富度和优势度。零值比例不参与标记。

63. IQR 规则#

Q1 = 第一四分位数
Q3 = 第三四分位数
IQR = Q3 - Q1
下限 = Q1 - 1.5 × IQR
上限 = Q3 + 1.5 × IQR

超出范围即标记为异常，等同于 Tukey 箱线图规则。

64. 高端和低端异常#

两个方向都会检测：深度、丰富度或优势度过低或过高。实际计算也会识别异常低的优势度。

65. IQR 最低条件#

少于四个值、全部缺失或 IQR 为零时，不检测该指标异常。无异常可能来自真正均一、样本太少或没有变异。

66. 样本状态#

至少一个指标异常则标记 Outlier，否则为 Standard。不会自动删除样本。

67. 信号数量#

表示深度、丰富度、优势度中异常指标的数量，取 0–3。信号越多，审查优先级越高。

68. 异常分数#

每个指标超出边界的距离以 IQR 单位表示，并求和。

68.1. 解释#

分数越高表示超出更远，但它不是概率、p 值、通用质量分数或删除阈值。

69. 异常优先顺序#

按信号数量、总分和 reads 排序。第一项成为重点样本。

70. 异常摘要#

显示异常总数、比例、各指标异常数、最常见信号和最受影响的组。

71. 组内异常集中度#

异常比例 = 组内异常样本数 ÷ 组内样本总数 × 100

显示最受影响的四个组。

71.1. 颜色阈值#

比例 视觉等级
≥ 30% 危险
15–<30% 警告
<15% 低

这些只是视觉约定，不是统计阈值。

72. 全局检测与分组解释#

异常阈值是全局计算的，然后再按组计算比例。自然不同的组可能集中很多异常，但并不表示技术故障。

73. 需关注样本表#

包含 SampleID、组、信号、信号数、分数、reads、丰富度和优势度，只列出至少一个 IQR 异常的样本，并支持搜索、筛选和导出。

74. 完整样本表#

包含 SampleID、组、信号、reads、丰富度、优势度、零值比例和状态。异常样本排在前面。

75. 异常值不代表什么#

异常值不自动等于错误、污染、应删除样本、测序失败或坏对照。可能是真实生物差异、组差异、低生物量或罕见事件。必须结合 metadata、实验设计、对照、过滤和图表判断。

76. 表格与日志#

初始折叠，包含 OTU table、分类表、metadata、完整性和过滤日志。

77. 表格摘要#

显示 OTU、分类表、metadata 的维度，以及可导出日志行数。维度不包含为显示新增的标识符列。

78. 显示的 OTU table#

标准化为分类单元在行、样本在列，并新增 ASV 列，即使实际单位是 OTU 或 ZOTU。

78.1. 原始方向#

导出的是标准化显示方向，不一定保留原始方向。

78.2. 内容#

数值不变，可能仍为整数、小数、负值、转换值或缺失值。

79. 显示的分类表#

包含 ASV 列和分类层级。

79.1. 层级名称#

空名称或重复名称仅为显示/导出而变为唯一，不修改 phyloseq 中的 tax_table。

80. 显示的 metadata#

sample_data 的行名变为 SampleID 列。若已有同名列，会改为 SampleID_meta 等。原对象不变。

81. 交互式表格功能#

表格提供列筛选、搜索、纵向/横向滚动、固定首列、分页、复制和 CSV。大矩阵仍会先在 R 内存中完整准备。

82. 专用 CSV 导出#

文件名：

<dataset>_otu_table.csv
<dataset>_tax_table.csv
<dataset>_metadata.csv
<dataset>_filtration_logs.csv

82.1. 格式#

使用 write.csv()：逗号分隔、不导出行名、标识符作为显式列、缺失值采用 R 标准表示。

82.2. 视觉筛选#

专用按钮导出完整计算表，而不是仅导出当前可见或筛选后的行。

82.3. 缺少组件#

相应组件不存在时，可能导出空 CSV。

83. 分类完整性#

每个层级显示已填写和缺失比例，可区分接近完整、部分完整或大范围缺失的层级。

84. Metadata 完整性#

每个变量显示 R 类型、缺失比例和唯一值数量，可发现空列、近似常量、潜在分组变量、变为文本的数值列和近似唯一标识符。

85. 可分组变量#

指具有 2–15 个水平且非时间类型的列。这并不保证生物学意义。

86. 过滤日志#

读取：

attr(ps, "filtration_log")

主要查找 removed_taxa 和 removed_samples。

86.1. 删除的 ASV#

可包含 ID、丰度、出现率、原因、参数等。

86.2. 删除的样本#

可包含 SampleID、深度、原因和其他信息。

86.3. 无显式标识符#

若使用行名，则添加 ASV 或 SampleID 列。

87. 日志导出#

将分类单元和样本日志合并为一个 CSV，新增 log_type 列，取值 removed_taxa 或 removed_samples；缺少的列填充为 NA。

88. 过滤日志的范围#

日志只代表当前对象所附信息，不保证包含所有历史版本、外部步骤或手工修改，也不保证从未被覆盖。

89. 项目视图#

项目视图使用当前内存中 datasets() 的对象，不会直接读取磁盘上的所有项目。

90. 项目总体摘要#

包括已加载数据集数、参与比较的数据集数、样本数总和、丰度总和和平均稀疏度。

91. 累计样本数#

为各数据集样本数之和，不是唯一样本数。同一批样本在多个数据集中会被重复计数。

92. 累计 reads#

为所有数据集丰度之和。只有数值类型可比时才有意义；原始计数、比例和 CLR 不能直接相加解释。

93. 项目平均稀疏度#

是各数据集稀疏度的简单平均，每个数据集权重相同，与矩阵大小无关。

94. 项目汇总表#

包括 Dataset、ASV、样本、总 reads、均值/中位数、平均丰富度、稀疏度、分类完整性、metadata 缺失、组件、日志和删除数量。

95. 要比较的数据集#

多选器决定比较图包含哪些数据集。默认全选或恢复项目中的旧选择。它不修改注册表、活动数据集或对象内容。

96. 参考数据集#

仅用于相对参考差异图，不用于热图、点图、绝对柱状图或过滤比较。

96.1. 参考不在选择中#

若参考未被选择，图会静默使用第一个已选择数据集作为回退。应始终将参考加入选择。

97. 关键指标#

可选 ASV、样本、reads、平均丰富度和稀疏度。它影响综合文字和相对参考差异图。

98. 项目综合解读#

文字指出所选指标最高的数据集。最高不等于最好：更多 reads 可能是深度失衡，更多 ASV 可能是噪声，更多稀疏度表示更多零值。

99. 综合热图#

比较 ASV、样本、reads、平均丰富度和稀疏度。

99.1. 归一化#

归一化值 = (值 - 最小值) ÷ (最大值 - 最小值)

99.2. 相同值#

若所有数据集相同，则设为 0.5。

99.3. 解释#

颜色表示某一指标内部的相对位置。不同指标单位不同，不能直接互比；原始值可在提示中查看。

100. 比较点图#

使用相同的 0–1 归一化。它不是总评分、多变量分析或质量排名。

101. 相对参考差异#

差异 (%) =
(数据集值 - 参考值)
÷ 参考值
× 100

参考数据集本身不显示为柱形。

101.1. 参考为零#

参考值为零或缺失时不生成图。

101.2. 只有一个数据集#

除参考外至少还需一个数据集。

101.3. 指标相关解释#

正差异表示所选指标更高，不一定代表改进。

102. 过滤比较#

根据 filtration_log 显示删除的 ASV 和样本数。

102.1. 重要限制#

这是绝对数量，没有按初始 ASV、样本、reads 或数据集大小校正。

102.2. 无日志#

显示为缺失，不代表没有进行过滤。

103. 比较柱状图#

显示样本数、ASV、总 reads、平均丰富度和稀疏度的绝对值，不做归一化或统计检验。

104. 数据集可比性#

比较前需确认技术、标记、区域、流程、过滤、分类数据库、样本集合、丰度类型、转换水平和分类单位定义是否一致。

105. 不同标记的比较#

COI、16S、ITS 可用于描述性比较，但其 ASV 数、丰富度、reads 和稀疏度不是等价的生物学测量。

106. 过滤前后比较#

应确认过滤数据集确实来自原始数据集、比较同一批样本、丰度未转换、日志存在，并注意父数据集是否被重命名或删除。

107. 性能#

描述模块在内存中执行矩阵求和、所有数据集指标、完整表格转换、序列计算、稀释、Plotly 和多数据集比较。

107.1. 延迟初始化#

打开描述选项卡时才初始化，首次显示可能较慢。

107.2. 大型表格#

延迟渲染改善浏览，但完整表格仍在 R 中准备。

107.3. 稀释曲线#

数百条曲线可能使浏览器变慢，可使用 Top、Bottom 或异常值模式限制。

108. 故障排除#

108.1. 未显示数据集#

可能没有加载、打开了错误项目、导入失败或注册表缺失。使用 Input data、OpenMetaBar 或 Datasets。

108.2. 其他选项卡的数据集也改变#

描述选择器与全局活动数据集同步，这是正常行为。

108.3. 仅查看后项目显示未保存#

可能更改了活动数据集。若需要保留该选择，应保存项目。

108.4. Reads 为小数#

OTU table 可能已转换或归一化，深度和稀释不能按原始计数解释。

108.5. 丰富度看起来不合理#

可能来自转换值、负值、未修剪分类单元、深度差异、结构零或方向问题。丰富度只计 >0 的值。

108.6. 稀疏度过低#

NA 留在分母中但不算零。

108.7. 没有分组变量#

可能缺少 metadata、只有一个或超过 15 个水平、变量为日期或全缺失。

108.8. 数值变量作为组出现#

它只有 2–15 个不同值。若不适合分类解释，请勿选择。

108.9. 缺失值成为 NA 组#

描述模块将缺失值转为组标签，可在 Data Edition 中清理。

108.10. 查看日志似乎无作用#

它只选择子选项卡，不自动展开区域。

108.11. 序列显示缺失#

可能没有 refseq、缺少 Biostrings 或序列对象无效。

108.12. GC 异常#

可能有模糊碱基、短序列、多个标记或非 ACGT 字符。

108.13. 分类层级名称改变#

仅为显示而使名称唯一，原对象不变。

108.14. 出现 SampleID_meta#

metadata 已有 SampleID 列，描述模块保留 SampleID 用于行名。

108.15. 无法计算稀释曲线#

可能缺少 vegan、OTU table、足够样本/reads，或数据类型不适合。

108.16. 曲线来自前一个数据集#

更换数据集后未重新计算。再次点击计算。

108.17. 最大曲线数未生效#

全部样本模式目前忽略该限制。

108.18. 大组聚合曲线更高#

该组所有 reads 被相加，不是每样本平均。

108.19. 未检测到异常#

可能真正均一、样本太少、IQR 为零或存在缺失值。

108.20. 生物学正常样本被标记#

规则为全局计算，不是组内计算，应结合实验背景解释。

108.21. 很异常的样本未标记#

相关指标可能不参与、IQR 为零、样本太少、仅零值比例异常或数据已转换。

108.22. 某组 30% 异常显示红色#

这是内部视觉阈值，不是 p 值或组效应证据。

108.23. OTU 导出方向不同#

导出始终为分类单元在行。

108.24. CSV 与视觉筛选不一致#

专用按钮导出完整表；若要导出当前 DataTables 状态，请使用表格内置 CSV。

108.25. CSV 为空#

相应组件可能不存在。

108.26. 缺少日志#

可能从未在 BarCodeR 中过滤、属性丢失、对象来自其他工具或旧版本。

108.27. 项目视图重复计数样本#

跨数据集求和不去重。

108.28. 热图数值看起来相近#

每个指标单独归一化为 0–1。

108.29. 整列热图为 0.5#

所有数据集在该指标上相同。

108.30. 未使用所选参考#

参考不在比较选择中，应将其加入。

108.31. 差异图不工作#

可能参考为零/缺失、只选择一个数据集或指标缺失。

108.32. 过滤比较不公平#

它比较绝对数量，应相对初始大小解释。

108.33. 项目视图缓慢#

减少数据集、比较选择或避免打开大型表格。

109. 打开数据集时的检查清单#

  • 确认数据集名称、样本数和分类单元数。
  • 确认总丰度和 OTU table 是否为原始计数。
  • 检查分类、metadata、序列和日志。
  • 阅读稀疏度和深度警告。

110. 分组分析前的检查清单#

  • 选择有生物学意义的变量。
  • 检查水平、缺失值和组大小。
  • 避免将连续变量误作分类变量。
  • 查看组间深度、丰富度和异常值。
  • 不要把描述图当作统计检验。

111. 稀释前的检查清单#

  • 确认为原始、整数、非负计数。
  • 至少两个样本有 50 reads。
  • 选择正确数据集和分组。
  • 点击计算，并在更换数据集后重算。
  • 区分单样本曲线和组池曲线。
  • 不要把平台期当作最终验证。

112. 排除异常样本前的检查清单#

  • 查看三个指标、metadata、实验组、阳性/阴性对照和日志。
  • 查看深度和分类优势度。
  • 判断偏差是否为预期生物学现象。
  • 不在描述模块中删除。
  • 仅在有理由时使用 Filtration。

113. 比较数据集前的检查清单#

  • 相同丰度类型和单位定义。
  • 相同标记或明确比较目的。
  • 技术、过滤和样本具有可比性。
  • 参考数据集已加入选择。
  • 理解求和不去重和 0–1 归一化。
  • 不将“更高”解释为“更好”。

114. 当前限制#

114.1. 不验证原始计数#

转换数据可能使所有指标误导。

114.2. ASV 只是通用标签#

模块不知道单位的生成方法。

114.3. 不汇总系统发育树#

不显示 phy_tree 是否存在或一致。

114.4. 序列与分类单元未全面对齐验证#

仅描述现有序列。

114.5. 稀疏度和完整性为简单摘要#

可能掩盖异质性。

114.6. 诊断阈值为内部规则#

不是通用标准。

114.7. 异常值全局计算#

不在组内计算。

114.8. 零值比例不参与异常状态#

仅显示。

114.9. 稀释需手动重算#

更换数据集不会重置结果。

114.10. 全部样本模式不受曲线数限制#

可能产生很重的图。

114.11. 聚合曲线使用合并池#

不是样本平均。

114.12. 表格完整加载到内存#

大对象可能耗时。

114.13. 导出会重定向表格#

OTU table 导出为分类单元在行。

114.14. 显示时可能调整列名#

原 phyloseq 不变。

114.15. 项目视图直接求和#

样本和分类单元不去重。

114.16. 热图比较相对位置#

不是共同单位。

114.17. 过滤比较使用绝对数量#

未按初始大小校正。

114.18. 不进行统计检验#

所有差异仅为描述性。

115. 推荐流程#

  1. 导入后打开描述。
  2. 确认活动数据集、维度和组件。
  3. 阅读结构警告并确认丰度类型。
  4. 查看 reads—丰富度、分布和序列。
  5. 选择合理分组，检查异常值，并在计数数据上计算稀释。
  6. 查看表格、完整性和日志。
  7. 在项目视图比较数据集。
  8. 如需修改，进入 Data Edition 或 Filtration。
