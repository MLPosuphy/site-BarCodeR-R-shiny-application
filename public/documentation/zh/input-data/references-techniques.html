2. 架构与主要数据流#

fileInput rds_input
  → read_serialized_input()
  → detect_supported_object_type()
  → pending_obj / pending_type / pending_candidates
  → selection or confirmation modal
  → mt_prepare_loaded_phyloseq()
  → bcr_guard_ps() for a single dataset
  → datasets() registry
  → active_ds()
  → unsaved project state

2.1. 反应式状态与内存#

标识符 作用
pending_obj() 等待用户确认的已加载对象。
pending_type() 检测类型：数据集或项目。
pending_file_name() 上传文件的原始名称。
pending_object_name() 在 RData 文件中选择的对象名称。
pending_candidates() 多对象 RData 中找到的兼容候选对象。
datasets() 当前 BarCodeR 项目中全部数据集的反应式注册表。
active_ds() 下游模块默认使用的数据集名称。

2.2. 可追溯链#

single phyloseq
  → proposed label
  → add or replace modal
  → mt_prepare_loaded_phyloseq()
  → bcr_guard_ps()
  → datasets(new_registry)
  → active_ds(final_label)
  → detailed cleaning report

project object
  → datasets / ps_registry / list-of-phyloseq extraction
  → clean_project_phyloseq_list()
  → name collision resolution
  → merge or replace datasets()
  → active dataset restoration
  → aggregate restoration report

5. 验证与完整性保护#

层 函数 作用
序列化文件 readRDS() / load() 读取对象；RData 在隔离环境中加载。
对象检测 detect_supported_object_type() 识别 phyloseq、datasets/ps_registry 项目或 phyloseq 列表。
样本标识符 sanitize_sample_names() 音译字符、替换不安全字符并解决重复名称。
Metadata 空白 replace_empty_metadata_with_na() 把列转为字符并将空白单元格替换为 NA。
Phyloseq 结构 bcr_guard_ps() 要求包含 OTU table，并检查样本和分类单元标识符。
数据集名称 bcr_clean_label() / bcr_make_unique_label() 在注册表中创建安全且唯一的键。
