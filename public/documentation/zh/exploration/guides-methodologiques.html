探索 — 方法指南

1. 作用与结构#

探索用于可视化、汇总和比较项目中的 phyloseq 对象。它包含六个工具：Barplot、Alpha 多样性、Venn/UpSet、Heat Tree、系统发育树和分类赋值质量。

这些工具并非全部只是描述性图表。单个分类单元比较、Alpha 统计、ANCOM-BC 和 Faith PD 组间比较属于推断分析。明显的图形差异并不自动等于统计显著。

2. 通用工作方式#

大多数子模块把科学计算和视觉渲染分开。数据集、分组、层级、指数、本地过滤和统计方法改变后，需要重新计算；颜色、尺寸、标签、方向和布局通常只重用上一次计算。

修改科学参数后，旧图可能继续显示。应检查“需要重新计算”“分析已更新”“需要重新生成图形”和“需要保存”等状态。

多个本地选择器会跟随全局活动数据集，但本地选择通常不会重设 active_ds()。Alpha 和 Venn 可以独立使用多个数据集。

3. 本地过滤#

Barplot、Alpha、Venn、Heat Tree 和分类质量可以使用子模块自己的临时过滤：

注册表数据集 → 本地临时过滤 → 探索结果

它不会覆盖全局数据集，不会在其他探索工具中自动生效，也不会创建持久化 phyloseq。需要保留时，应在“过滤”模块中重建条件、另存数据集并保存项目。

4. Barplot#

Barplot 按样本或元数据组显示分类组成，可使用原始或相对丰度。

OTU 表是必需的；分类层级需要 taxonomy，分组需要 metadata。聚合使用 tax_glom(..., NArm = FALSE)，从而保留未赋值分类单元。用户可定义哪些标签归为“未知”。

无分组时，一根柱代表一个样本。按组时，先汇总组内 reads，再计算组成，因此是按测序深度加权的 pooled composition，不是各样本比例的平均。

Top N 基于当前显示的数据计算，其余分类单元归为“其他”。丰度阈值在 Top N 之后应用，被删除的行不会自动归入“其他”。100% 堆叠图会把剩余部分视觉归一化为 100%。

可使用堆叠、分组、dodged、水平、总分类单元柱图和 lollipop 等形式，并可排序和自定义颜色。

选择一个分类单元后，可按组比较其相对丰度。模块根据组数、样本量、正态性和方差自动选择 Student、Welch、Wilcoxon、ANOVA/Tukey、Welch ANOVA 或 Kruskal-Wallis，并可加入协变量。这是定向检验，不等同于全局组成差异分析。

5. Alpha 多样性#

可计算 Observed、Shannon、Simpson、InvSimpson、Chao1、ACE、Fisher 和 Pielou。Observed ≤ 1 时 Pielou 缺失。

系统不会强制把非整数数据四舍五入。Observed、Shannon、Simpson、InvSimpson 和 Pielou 仍可计算，但 Chao1、ACE 和 Fisher 在非计数数据上返回缺失。

分组变量只有在所有分析数据集中都存在时才会提供。跨数据集比较前，应确认标记、流程、分类单元定义、丰度类型和过滤一致。

可选稀释使用 rarefy_even_depth() 和固定种子 2026。目标深度为零时，每个数据集分别使用自己的正最小值，而不是共同深度。稀释会丢失 reads，也可能丢失样本。

深度诊断包括稀释曲线和 Good 覆盖度：

1 - singleton 数 / 总 reads

这些诊断要求整数计数。

统计子页独立运行。一个解释变量时自动选择参数或非参数检验；多个变量时构建 Y ~ V1 + V2 或 Y ~ V1 * V2 模型，并可提供残差、方差、R²、Breusch-Pagan 和 emmeans 诊断。稀疏交互单元可能不稳定。

6. Venn 与 UpSet#

该工具比较存在/不存在。元素在本地过滤后只要出现一次就视为存在。

跨数据集模式把数据集作为集合；数据集内模式把 metadata 水平作为集合。元素可以是分类标签或完全相同的 RefSeq 字符串。序列模式不进行比对或相似性聚类。

正则表达式可删除模糊标签；标准化可统一层级前缀、空格、下划线和大小写，但也可能合并原本不同的标签。具有同一标签的 ASV 会聚合，出现率按样本重新计算。

Venn 最多支持七个集合，更多集合会自动切换到 UpSet。UpSet 可排序、筛选交集，并显示 reads 或出现率注释。

交集表示共享存在，不表示丰度相同。核心或唯一分类单元受过滤、深度、组大小、分类层级和标签标准化影响。

7. Heat Tree#

Heat Tree 把值映射到分类层级。模式包括简单树、两组描述性差异和多比较矩阵。

简单指标包括总和、均值、出现次数、贡献 ASV 数、中位数、方差、平均相对丰度、对数丰度、优势度和相对频率。部分指标可仅使用出现样本，也可包含所有样本的零值。

快速差异模式计算两组中位数的 log2 比值。它是描述性的，没有 p 值、多重校正或组成偏差修正。

ANCOM-BC 提供组成差异推断，可配置协变量、出现率、最小库大小、p 值校正、alpha、结构零、收敛、伪计数、敏感性和随机效应。检验 alpha 改变时需要重新计算；计算后的 q 和 logFC 阈值只是显示过滤。

ANCOM-BC 对每个层级和对比单独运行。k 组产生 k(k-1)/2 个两两对比，层级 × 对比数量可能非常大，尤其是 ASV 层级。取消可能只能在两个任务之间生效。

8. 系统发育树#

必须已有 phy_tree；模块不会从序列重建树。它使用分类聚合、出现率、总丰度、Top N 和标签清理，而不是完整本地过滤。

模糊标签可改写为 unclassified <最后已知祖先>。过滤后至少保留三个分类单元。

叶节点可显示总和、均值、相对丰度、中位数、方差、出现率、对数丰度或优势度。诊断包括叶数、内部节点、枝长、根、超度量、二叉性、总长度和高度。

Faith PD 在 picante 可用时计算。它在显示用的出现率、丰度和 Top N 过滤之前计算，因此这些视觉参数不会改变 Faith 表。根树与无根树的值不能直接等同。

树不完整时，缺失分类单元可能被忽略。BarCodeR 报告缺失数和 reads 覆盖率。两组比较使用 Wilcoxon，三组以上使用 Kruskal-Wallis。Faith PD 对丰富度和测序深度敏感。

渲染引擎包括 ggtree、phyloseq 和 ape，完整交互主要依赖 ggtree。

9. 分类赋值质量#

该工具按层级计算已赋值分类单元比例、已赋值 reads 比例，以及连续的严格赋值深度。

分类单元比例和 reads 加权比例可能差异很大：大量未知 ASV 可能只占很少 reads。

未赋值模式包括 NA、空值、unknown、unclassified、uncultured、environmental、metagenome、空层级前缀和 sp.。无效 regex 会按字面处理。

严格深度在第一次层级中断处停止；较低层级有值也不能修复较高层级缺失。

污染物模式可在所有层级搜索。排除只影响质量计算，不修改数据集，但会改变分母并可能提高赋值率。默认污染物必须按标记调整。

结果可按层级、累计深度或两者显示，并可使用百分比或绝对数量。

10. 描述性与推断性分析#

Barplot 主图、Venn、简单 Heat Tree、系统发育图和分类质量主要是描述性的。定向 Barplot 检验、Alpha 统计、ANCOM-BC 和 Faith 比较属于推断分析。视觉差异不等于显著性，显著性也不等于因果关系。

11. 历史记录与可重复性#

每个工具在项目中拥有独立历史目录：barplot/、alpha_div/、venn_diag/、heat_tree/、phylo_tree/figures/ 和 tax_quality/。

显示结果不会自动保存。快照可包含 PNG、RDS、元数据、参数、计算数据、日志和 XLSX。删除历史条目会直接删除文件，没有内部回收站。

较新的快照可以生成 R 代码。代码可能依赖快照 RDS、包版本和专用依赖，发布前应审查。旧快照可能没有代码。日志记录数据、过滤、参数、检验、警告和错误，其中部分文本仍为法语。

12. 科学可比性#

比较前应确认标记、区域、技术、去噪/聚类、ASV/OTU 定义、分类数据库、层级、样本、丰度类型、过滤、归一化和深度。

稀释、Chao1、ACE、Fisher、Good 覆盖度、ANCOM-BC 以及 reads/出现率汇总假设计数型数据。CLR 或对数数据会改变“存在”和“总量”的含义。

分类聚合会改变分析单位。组大小会影响 pooled composition 和检测稀有分类单元的概率。全局分析需要合适的多重检验和组成方法。

13. 性能与依赖#

成本随样本、分类单元、数据集、指数、集合、层级、对比和树叶数量增加。多层级 ANCOM-BC 和大型交互树尤其昂贵。

可能需要 phyloseq、vegan、metacoder、ANCOMBC、ComplexUpset、ape、ggtree、picante、plotly、emmeans、lmtest 和 openxlsx。包缺失时，输出可能被禁用或回退；应查看日志。

通过过滤、按层级聚合、限制组/层级/对比和减少交互性来降低成本。

14. 常见问题#

现象 主要原因
图形与参数不一致 需要重新计算
本地过滤未出现在另一工具 状态相互独立
组 Barplot 不是平均值 reads 被 pooled
Chao1/ACE/Fisher 缺失 非整数数据
Venn 自动变 UpSet 超过七个集合
ANCOM-BC 很慢 层级、对比或 ASV 过多
q 阈值改变节点但未重算 只是视觉过滤
Top N 改变但 Faith 不变 Faith 在显示过滤前计算
排除污染物后赋值率上升 分母改变
历史为空 项目错误或未保存结果

15. 使用检查表#

探索前：确认项目、数据集、计数/转换状态、表、层级、metadata 类型、组和本地过滤。

统计前：确认重复、缺失值、深度、检验假设、协变量、交互、多重校正和效应大小。

ANCOM-BC 前：使用合适计数，定义组和参考，从高层级开始，限制层级与对比，并区分计算 alpha 和显示 q。

保存前：确保计算和渲染均为最新，检查标题、颜色、尺寸和日志，并保存历史与所需表格。

16. 主要限制#

子模块本地状态独立、图形可能过期、组组成采用 pooled 计算、非整数数据限制丰富度估计、零目标稀释按数据集分别计算、Venn 使用首次出现、标签标准化可能合并类别、中位数 Heat Tree 非推断、ANCOM-BC 扫描昂贵、Faith 可能基于部分树、分类质量依赖 regex、历史依赖当前项目。

17. 推荐流程#

  1. 在 Description 检查数据集。
  2. 确认是原始计数还是转换值。
  3. 检查组和重复。
  4. 仅把本地过滤用于探索试验。
  5. 从简单描述图开始。
  6. 选择合适层级并限制显示元素。
  7. 科学参数改变后重新计算。
  8. 设计有效后再运行统计。
  9. 阅读日志和诊断。
  10. 保存图、参数和表。
  11. 审查可重复 R 代码。
  12. 在 Filtration 中持久化必要过滤并保存项目。
